# workflow 문서 인덱스

AI 에이전트 작업 방식, 브랜치·이슈·PR 운영, 문서 작성 규칙을 둔다. 이 폴더에는 지금 따르는 기준만 둔다.

| 문서 | 역할 |
|---|---|
| `AGENTS-및-AI문서-운영기준.md` | 루트·모듈별 `AGENTS.md`, `docs/`, ADR·현재 상태 문서의 책임 분리와 공개 범위 |
| `PR-작성-및-머지-절차.md` | PR 전 확인, 초안, 승인, 생성, squash 머지, 이슈 닫기 |
| `문서-작성-및-학습-보고-규칙.md` | 작업 보고서 작성 기준, 문서 머리 형식, 색인 고치기와 대체 표시 |
| `클라우드-세션-작업-절차.md` | 클라우드 세션에서 이어 하기: 보이는 자료, 할 일/못 할 일, 테스트, 공개 검사, 넘기기 |

브랜치, 이슈, 커밋, PR의 공개 협업 규칙 원본은 루트 `CONTRIBUTING.md`이고, 모듈별 PR 점검표는 `backend/`, `frontend/`, `ai-server/`의 `AGENTS.md`다. 옛 workflow 보고서와 참고 자료는 `docs/archive/workflow/`에 있다(로컬 전용). 충돌하면 이 폴더의 문서가 우선한다.
