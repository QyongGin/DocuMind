# workflow 문서 인덱스

AI 에이전트 작업 방식, 브랜치·이슈·PR 운영, 문서 작성 규칙을 둔다. 이 폴더에는 지금 따르는 기준만 둔다.

| 문서 | 역할 |
|---|---|
| `AGENTS-및-AI문서-운영기준.md` | 루트·모듈별 `AGENTS.md`, `docs/`, ADR·현재 상태 문서의 책임 분리와 공개 범위 |
| `AI-에이전트-작업-흐름.md` | 이슈 시작, 브랜치, 커밋 대상, PR 흐름 |
| `GitHub-develop-브랜치-및-파생이슈-운영기준-20260606.md` | develop 중심 브랜치 전략, parent/child 이슈 |
| `PR-작성-및-머지-절차.md` | PR 전 확인, 초안, 승인, 생성, squash 머지, 이슈 닫기 |
| `PR-클린코드-체크리스트.md` | PR 전 점검표 |
| `문서-작성-및-학습-보고-규칙.md` | 작업 보고서 작성 기준 |
| `실행계획-ExecPlan-템플릿.md` | 오래 걸리는 작업용 실행 계획 템플릿 |
| `클라우드-세션-작업-절차.md` | 클라우드 세션에서 이어 하기: 보이는 자료, 할 일/못 할 일, 테스트, 공개 검사, 넘기기 |

옛 workflow 보고서와 참고 자료는 `docs/archive/workflow/`에 있다(로컬 전용). 충돌하면 이 폴더의 문서가 우선한다.
