# 알려진 문제와 운영 주의사항 (known issues)

> 고치지 않았거나 고칠 때까지 피해 가야 하는 동작을 모은다. 고치면 해당 줄을 지우고 PR에 적는다. 2026-10-07에 `memory-bank/activeContext.md`의 "반드시 알아야 할 사실"에서 옮겼다.

## 데스크탑·WSL

| 증상 | 원인·확인 | 대응 |
|---|---|---|
| `ssh desktop`이 안 됨 | 데스크탑은 작업할 때만 켠다(ADR-0003) | 맥북 Tailscale → 데스크탑 전원 → WSL 순으로 확인. 절차: `local-gpu/데스크탑-작업-시작-종료-절차.md` |
| 재부팅 뒤 맥북 → WSL 직접 SSH가 시간 초과 | 2026-10-04 실측 | `ssh desktop-win "wsl -d Ubuntu -- bash -s" < 스크립트`로 우회 |
| Ubuntu 창을 닫으면 WSL이 꺼짐 | 데스크탑에 `.wslconfig`가 없음 | 작업 중에는 창을 닫지 않는다 |
| 원격 빌드 때 자격 증명 오류 | Docker Desktop 자격 증명 도우미 | `DOCKER_CONFIG=~/.docker-nocreds`(빈 config)로 빌드 |
| Windows 주소(`<Windows IP>:19580`)로 연 화면에서 로그인·질문이 403 | 백엔드 CORS 허용 목록에 WSL 주소만 있음 | 브라우저는 `http://<WSL IP>:19580`으로 연다(실제 값은 `docs/local/접속정보.md`) |
| 업로드 중 데스크탑이 꺼지면 문서가 "처리 중"으로 남아 관리 화면에서 못 지움 | 2026-10-04 발생(Windows 이벤트 1074) | DB에서 실패로 바꾸고 색인 정리 후 이어 올림. 재시작 뒤 복구는 M4 할 일 |

## Docker·데이터 저장소

| 증상 | 원인·확인 | 대응 |
|---|---|---|
| `docker compose down -v`로 색인·DB가 지워짐 | 볼륨 삭제 | 금지. 백업: `deploy/backup.sh documind_desktop`(ADR-0016) |
| MySQL 헬스체크가 초기화 도중에도 healthy | `mysqladmin ping`이 로그인 거부도 성공으로 침 | 백업·복원 스크립트는 TCP 로그인으로 확인. compose 수정은 M4 |
| Chroma `/api/v2/version`이 1.0.0·1.5.5 모두 `"1.0.0"` | 서버 응답 고정 | 버전은 이미지 ID와 `chroma --version`(1.5.5 이미지는 1.4.1)으로 확인 |
| 같은 문서를 다시 색인하면 벡터가 미세하게 다름 | 묶음 임베딩 비결정성(16개 묶음 두 번에 9/16만 비트 동일, 코사인 ≥0.998) | 베이스라인은 색인 백업 이름과 함께 기록 |
| 데스크탑 `.env` 문맥 설정 | `OLLAMA_NUM_CTX=8192`, `OLLAMA_EMBEDDING_NUM_CTX=2048`(원본 `.env.bak-20261003-before-pr2`) | ADR-0011 |

## GitHub·저장소

| 주의 | 내용 |
|---|---|
| `Closes #N`이 연결되지 않음 | 기본 브랜치가 main이라 develop PR로는 닫히지 않고, main 대상 릴리스 PR에서도 두 번 연결되지 않았다(#120·#122) → 릴리스 뒤 직접 닫는다(`docs/workflow/PR-작성-및-머지-절차.md` §6) |
| 머지 안 된 옛 작업 | `archive/*` 태그 14개로 원격에 보존(`git tag -l 'archive/*'`) |
| README 작성 worktree | `~/Developer/Project/DocuMind-readme`(`docs/readme` 브랜치)에 미커밋 변경이 있다. 건드리지 않는다 |
