# 데스크탑 작업 시작·종료 절차

> 데스크탑은 전기 요금 때문에 **작업할 때만 켠다** (2026-09-30 결정). 실행 서버는 데스크탑이고, 명령은 맥북에서 보낸다.
> 상시 가동과 자동 기동은 학교 서버에서 운영할 때(총괄계획 M6) 다룬다.

## 한 번만 해 두면 편한 설정 (선택)

| 설정 | 효과 |
|---|---|
| Docker Desktop → Settings → General → "Start Docker Desktop when you sign in" 체크 | 로그인하면 Docker가 자동으로 켜진다 |
| `%USERPROFILE%\.wslconfig`에 아래 두 줄 (PowerShell: `Set-Content -Path "$env:USERPROFILE\.wslconfig" -Value "[general]`r`ninstanceIdleTimeout=-1"`) | Ubuntu 창을 닫아도 WSL이 꺼지지 않는다. 맥북에서 원격으로 한 번 켜 두면 계속 유지된다 |

```ini
[general]
instanceIdleTimeout=-1
```

WSL은 기본값으로 마지막 창이 닫히고 15초 뒤 꺼진다. 2026-08~09에 서버가 54일간 꺼져 있었던 원인이다.

## 작업 시작

1. 데스크탑을 켜고 로그인한다. Docker Desktop이 "Engine running"인지 확인한다.
2. 맥북 메뉴 막대에서 **Tailscale을 연결**한다.
3. Ubuntu(WSL)를 켠다. 둘 중 하나를 쓴다.
   - 데스크탑에서 시작 메뉴 → Ubuntu (창은 열어 둔다)
   - 맥북에서 `ssh desktop-win wsl -d Ubuntu --exec /bin/true` (위 `.wslconfig` 설정을 했을 때만 계속 켜져 있다)
4. 맥북에서 서비스를 최신 코드로 올린다.

```bash
ssh desktop 'cd ~/DocuMind && git pull --ff-only && docker compose --project-name documind_desktop -f docker-compose.yml -f docker-compose.gpu.yml --env-file .env up -d --build'
```

5. 상태를 확인한다. 모든 서비스가 `healthy`면 준비 완료다.

```bash
ssh desktop 'cd ~/DocuMind && docker compose --project-name documind_desktop -f docker-compose.yml -f docker-compose.gpu.yml --env-file .env ps'
```

6. 브라우저에서 `http://<WSL IP>:19580`으로 접속한다 (데스크탑 WSL의 Tailscale IP, 백엔드 `APP_CORS_ALLOWED_ORIGINS`에 등록된 주소). Windows IP(`<Windows IP>`)로 열면 화면은 뜨지만 로그인·질문이 403으로 막힌다(2026-10-03 확인).

## 작업 끝

0. (문서를 많이 올리거나 지웠다면) 서비스를 멈추기 전에 DB·색인을 백업한다. 절차: `docs/deployment/DB-색인-백업-복원-절차.md`

```bash
ssh desktop 'cd ~/DocuMind && deploy/backup.sh documind_desktop'
```

1. 맥북에서 서비스를 멈춘다.

```bash
ssh desktop 'cd ~/DocuMind && docker compose --project-name documind_desktop -f docker-compose.yml -f docker-compose.gpu.yml --env-file .env stop -t 60'
```

   `-t 60`은 멈출 때 기다리는 시간이다. 기본 10초로는 MySQL이 정리를 끝내기 전에 강제 종료(종료 코드 137)될 수 있다(2026-10-04 확인).
   맥북에서 `ssh desktop`이 안 되면 Windows 노드를 거친다: `ssh desktop-win "wsl -d Ubuntu -- bash -s"`에 같은 명령을 표준 입력으로 보낸다.

2. 데스크탑을 끈다. 업로드 같은 긴 작업이 도는 중에는 끄지 않는다(2026-10-03 업로드 중 꺼져 문서 1개를 정리하고 다시 올렸다).

서비스를 멈추지 않고 끄면, 다음에 Docker가 켜질 때 서비스도 자동으로 같이 켜진다(`restart: unless-stopped`, #118). 게임 등 다른 용도로 켰을 때 GPU 메모리를 차지하므로, 작업을 끝낼 때는 멈춰 두는 것을 권장한다.

## 하지 말 것

- `docker compose down -v`: 볼륨(DB, 색인, AI 모델)이 지워진다.
- 참고: `-v` 없는 `docker compose down`은 이제 안전하다. 색인이 볼륨에 저장되기 때문이다(#115).

## 문제가 생기면

| 증상 | 확인 |
|---|---|
| `ssh desktop`이 안 됨 | 맥북 Tailscale이 켜졌는지, 데스크탑 Ubuntu가 켜졌는지 (`ssh desktop-win "wsl -l -v"`에서 Ubuntu가 Running인지) |
| `docker` 명령이 실패함 | Docker Desktop이 켜졌는지 |
| 브라우저가 안 열림 | 상태 확인 명령에서 frontend가 `healthy`인지 |
