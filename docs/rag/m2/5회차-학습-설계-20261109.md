# M2 학습 5회차 설계 — 근거 안의 비슷한 다른 사실로 단정하지 않게

> 상태: 설계 중(2026-11-09). 이슈 #245. 앞 단계: `개선-1단계-결과-20261109.md`, 개선 설계 5장 B(`개선-설계-20261105.md`), ADR-0054. 결정은 한 번에 하나씩 정해 이 문서에 적고, 설계가 끝나면 ADR로 남긴다.

## 1. 왜 5회차인가

- [실측] 학습 1~4회차는 근거가 모자랄 때 거절하는 쪽으로 모델을 옮겼다. 4회차는 개발셋 오답 11 → 3이지만 정답 98 → 87, 과잉 거절 7 → 17이 의미 있게 나빠졌다(`4회차-학습-결과-20261105.md`).
- [실측] 4회차 모델에 재순위를 켜면 정답 98, 과잉 거절 5로 학습 전 모델(98, 7)과 같은 수준이 된다. 대신 근거 안의 비슷한 다른 사실(표의 다른 칸·행, 다른 절차, 다른 해·대상의 값)로 단정한 새 오답이 9개 생겨 오답 10/149, 답없음 거절 25/28로 운영 선 밖이다(`개선-1단계-결과-20261109.md`).
- 목표: 재순위를 켠 근거에서 "질문과 같은 대상의 사실만 골라 답하고, 없으면 거절한다"를 배우게 한다. 판정은 지금 규칙(ADR-0033 운영 선, ADR-0035·0054 채택 규칙)이다.

## 2. 정할 것(한 번에 하나)

1. **정함(2026-11-09)**: 학습 예시의 `[검색 근거]`(출처 1~8)는 재순위를 켠 검색으로 뽑는다(TEI + bge-reranker-v2-m3, 후보 20). 근거 블록 원문 넣기는 끈다. 5회차가 채택되면 운영 챗봇도 재순위를 켠다.
   - [실측] 학습 입력과 운영 입력이 같아야 배운 대로 답한다(ADR-0047 원칙). 4회차는 재순위 없이 배운 뒤 재순위 근거를 받자 새 오답 9개를 냈다.
   - [실측] 재순위를 켠 4회차 모델은 정답 98, 과잉 거절 5로 학습 전 모델과 같거나 낫다. 5회차는 남은 오답(10개)과 답없음 실패(3개)를 겨냥하면 된다.
   - [실측] 재순위만 켜면 개발셋 프롬프트 205개가 모두 학습 도구 한도 8,192토큰 안이다(최대 7,736).
   - 버린 대안: 원문 넣기까지 켬(빠졌던 정답 근거 9문항이 모두 들어오지만 205개 중 15개가 8,192토큰을 넘고, 운영 문맥 12,288에 닿아 답 1개가 잘렸으며, 데스크탑 GPU 11.3 / 12.3GB로 여유가 없다), 지금 검색 그대로(근거가 빠진 문항은 학습해도 거절밖에 배울 수 없다).
   - 바뀌는 것: 학습 데이터를 만들 때 데이터셋용 스택에 재순위 컨테이너를 같이 띄운다. 운영에서 켜면 GPU 약 1.3GB, 질문당 약 0.2초(2026-11-09 평균 1.90 → 2.13초)가 는다.
2. **정함(2026-11-09)**: 학습 예시는 재순위 근거 8개 안에 질문과 같은 종류의 다른 값(다른 해·행·칸·대상·절차)이 함께 있는 질문을 골라 만든다. 목표 답은 그중 질문한 대상의 값을 고르고, 결론에 그 대상(학년도·학과·전형 등)을 다시 밝힌다(ADR-0049 범위 안). 답없음 예시는 정답 청크를 빼고 비슷한 사실이 남은 근거로(ADR-0048 방식) 적게 넣고, 같은 질문의 답 있는 예시와 함께 넣을 때는 정답 청크 유무가 분명한 것만 쓴다. 비율은 결정 3(학습 방식)과 함께 정한다.
   - [실측] 재순위를 켠 4회차 모델의 오답 10개 중 7개는 정답 근거를 받고도 근거 안의 다른 칸·행·해·절차를 고른 것이고, 3개는 답없음 문항에 비슷한 사실로 단정한 것이다(조사 문서 부록 B).
   - [원문] 비슷하지만 답이 없는 근거가 가장 해롭고, 그런 근거를 골라 학습하면 일반 RAG 데이터로 학습한 것보다 낫다. 답없음 예시는 적게 넣어도 거절을 배우고, 거절 학습과 비슷한 입력의 엇갈린 지시는 과잉 거절을 부른다(`../research/방해근거-학습데이터-구성-조사-20261109.md` 자료 1·2·3·7·9·10).
   - 버린 대안: 근거 풀이·인용형 목표 답(답 형식과 백엔드 변환이 바뀌고 답이 길어짐, 5회차가 실패하면 다음 후보), 방해 문서 무작위 추가(우리 근거에는 재순위가 고른 비슷한 청크가 이미 있고, 정답 문서를 뺀 예시의 목표가 외운 답이 되어 근거에 있는 것만 답하는 원칙과 맞지 않음).
3. 학습 방식과 시작 모델: 지도 학습 또는 선호 학습, 학습 전 모델에서 새로 또는 4회차에서 이어서.
4. 학습 위험 확인과 판정 규칙.
