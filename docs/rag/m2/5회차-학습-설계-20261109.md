# M2 학습 5회차 설계 — 근거 안의 비슷한 다른 사실로 단정하지 않게

> 상태: 설계 끝(2026-11-09), 결정 ADR-0055. 이슈 #245. 앞 단계: `개선-1단계-결과-20261109.md`, 개선 설계 5장 B(`개선-설계-20261105.md`), ADR-0054. 결정은 한 번에 하나씩 정해 이 문서에 적고, 설계가 끝나면 ADR로 남긴다.

## 1. 왜 5회차인가

- [실측] 학습 1~4회차는 근거가 모자랄 때 거절하는 쪽으로 모델을 옮겼다. 4회차는 개발셋 오답 11 → 3이지만 정답 98 → 87, 과잉 거절 7 → 17이 의미 있게 나빠졌다(`4회차-학습-결과-20261105.md`).
- [실측] 4회차 모델에 재순위를 켜면 정답 98, 과잉 거절 5로 학습 전 모델(98, 7)과 같은 수준이 된다. 대신 근거 안의 비슷한 다른 사실(표의 다른 칸·행, 다른 절차, 다른 해·대상의 값)로 단정한 새 오답이 9개 생겨 오답 10/149, 답없음 거절 25/28로 운영 선 밖이다(`개선-1단계-결과-20261109.md`).
- 목표: 재순위를 켠 근거에서 "질문과 같은 대상의 사실만 골라 답하고, 없으면 거절한다"를 배우게 한다. 판정은 지금 규칙(ADR-0033 운영 선, ADR-0035·0054 채택 규칙)이다.

## 2. 정할 것(한 번에 하나)

1. **정함(2026-11-09)**: 학습 예시의 `[검색 근거]`(출처 1~8)는 재순위를 켠 검색으로 뽑는다(TEI + bge-reranker-v2-m3, 후보 20). 근거 블록 원문 넣기는 끈다. 5회차가 채택되면 운영 챗봇도 재순위를 켠다.
   - [실측] 학습 입력과 운영 입력이 같아야 배운 대로 답한다(ADR-0047 원칙). 4회차는 재순위 없이 배운 뒤 재순위 근거를 받자 새 오답 9개를 냈다.
   - [실측] 재순위를 켠 4회차 모델은 정답 98, 과잉 거절 5로 학습 전 모델과 같거나 낫다. 5회차는 남은 오답(10개)과 답없음 실패(3개)를 겨냥하면 된다.
   - [실측] 재순위만 켜면 개발셋 프롬프트 205개가 모두 학습 도구 한도 8,192토큰 안이다(최대 7,736).
   - 버린 대안: 원문 넣기까지 켬(빠졌던 정답 근거 9문항이 모두 들어오지만 205개 중 15개가 8,192토큰을 넘고, 운영 문맥 12,288에 닿아 답 1개가 잘렸으며, 데스크탑 GPU 11.3 / 12.3GB로 여유가 없다), 지금 검색 그대로(근거가 빠진 문항은 학습해도 거절밖에 배울 수 없다).
   - 바뀌는 것: 학습 데이터를 만들 때 데이터셋용 스택에 재순위 컨테이너를 같이 띄운다. 운영에서 켜면 GPU 약 1.3GB, 질문당 약 0.2초(2026-11-09 평균 1.90 → 2.13초)가 는다.
2. **정함(2026-11-09)**: 학습 예시는 재순위 근거 8개 안에 질문과 같은 종류의 다른 값(다른 해·행·칸·대상·절차)이 함께 있는 질문을 골라 만든다. 목표 답은 그중 질문한 대상의 값을 고르고, 결론에 그 대상(학년도·학과·전형 등)을 다시 밝힌다(ADR-0049 범위 안). 답없음 예시는 정답 청크를 빼고 비슷한 사실이 남은 근거로(ADR-0048 방식) 적게 넣고, 같은 질문의 답 있는 예시와 함께 넣을 때는 정답 청크 유무가 분명한 것만 쓴다. 비율은 결정 3(학습 방식)과 함께 정한다.
   - [실측] 재순위를 켠 4회차 모델의 오답 10개 중 7개는 정답 근거를 받고도 근거 안의 다른 칸·행·해·절차를 고른 것이고, 3개는 답없음 문항에 비슷한 사실로 단정한 것이다(조사 문서 부록 B).
   - [원문] 비슷하지만 답이 없는 근거가 가장 해롭고, 그런 근거를 골라 학습하면 일반 RAG 데이터로 학습한 것보다 낫다. 답없음 예시는 적게 넣어도 거절을 배우고, 거절 학습과 비슷한 입력의 엇갈린 지시는 과잉 거절을 부른다(`../research/방해근거-학습데이터-구성-조사-20261109.md` 자료 1·2·3·7·9·10).
   - 버린 대안: 근거 풀이·인용형 목표 답(답 형식과 백엔드 변환이 바뀌고 답이 길어짐, 5회차가 실패하면 다음 후보), 방해 문서 무작위 추가(우리 근거에는 재순위가 고른 비슷한 청크가 이미 있고, 정답 문서를 뺀 예시의 목표가 외운 답이 되어 근거에 있는 것만 답하는 원칙과 맞지 않음).
3. **정함(2026-11-09)**: 5회차는 4회차 모델(`ax40light-r4`)의 어댑터에서 이어 선호 학습(DPO)을 한다. 기준 모델은 4회차이고, 손실(DPO + sft)과 β 0.1·학습률 1e-5·반복 2번은 4회차와 같게 둔다. 선호 쌍의 비선호 답은 4회차 × 재순위가 학습 질문에서 실제로 낸 비슷한 값 오답(답없음 질문이면 비슷한 사실로 단정한 답), 선호 답은 질문 대상의 값을 고른 목표 답(답없음이면 거절 문장과 확인처)이다. 쌍 비율은 실제로 나온 실패 비율대로 두고(개발셋 기준 비슷한 값 오답 7 : 답없음 단정 3) 거절 쪽 쌍이 그보다 많지 않게 한다. 먼저 학습 질문 200개로 실패 쌍이 몇 개 나오는지 재고 묶음 크기를 정한다.
   - [실측] 출발점: 4회차 × 재순위는 정답 98·과잉 거절 5로 학습 전 모델(98·7)과 같거나 낫고, 남은 실패는 비슷한 값 오답 7과 답없음 단정 3이다(`개선-1단계-결과-20261109.md` 3·4절).
   - [원문] 학습 전 A.X에 재순위를 켜면 오답률이 6.0 → 12.1%로 늘었다(p=0.049, `2단계-A.X-새기준선-20261020.md`). 학습 전 모델에서 새로 시작하면 이 오답부터 다시 줄여야 한다.
   - [실측] 지도 학습 1~3회차는 모두 정답과 과잉 거절이 학습 전 모델보다 의미 있게 나빠졌다(`1회차-학습-결과-20261103.md`, `2회차-학습-결과-20261103.md`, `3회차-학습-결과-20261103.md`).
   - [원문] 거절을 가르치는 지도 학습은 과잉 거절로 이어질 수 있고 선호 학습이 이를 줄일 수 있다(조사 문서 자료 10, TACL 2025). 근거 기반 답과 올바른 거절을 선호 쌍으로 가르친 DPO는 27개 모델·데이터 조합 모두에서 올바른 거절과 근거 기반 답을 늘렸다(자료 8, ICLR 2025).
   - [실측] 4회차가 일반화하지 못한 원인은 쌍 구성이다. 3회차가 실제로 거절한 쌍이 학습에 7개뿐이었고 검증 쌍 선호 정확도는 0.43이었다(학습 쌍 95%, `4회차-학습-결과-20261105.md` 1·8절). 5회차는 모델이 실제로 낸 실패만 비선호 답으로 쓴다.
   - [계산] 재순위를 켠 4회차의 개발셋 실패율은 10/149(6.7%)다. 같은 비율이면 학습 질문 1,000개에서 실패 쌍이 약 67개 나온다. 결정 2대로 비슷한 값이 함께 든 질문만 고르면 더 많을 것으로 보지만, 200문항 시험으로 확인한다.
   - 버린 대안: 학습 전 모델에서 새로 지도 학습(1~3회차가 모두 정답·과잉 거절을 나빠지게 했고, 학습 전 × 재순위는 오답이 늘었던 조합), 4회차에서 이어 지도 학습(거절 버릇 위에 목표 답을 덧씌우는 방식이라, 과잉 거절을 줄인다는 근거가 선호 학습보다 약함).
   - 학습 위험 [판단]: 선호 답과 비선호 답이 모두 값을 말하는 답이라 "값이 여러 개면 답하지 말자"를 배울 수 있다 → 거절 쪽 쌍을 실패 비율보다 늘리지 않고, 학습 뒤 개발셋 과잉 거절을 따로 본다. 결론에 대상을 다시 밝히는 문구가 한 가지 틀로 굳을 수 있다 → 학습 전에 목표 답 결론의 문구 반복을 센다.
   - 확신도 중간. 검증 시점: 200문항 시험(실패 쌍 수), 학습 뒤 개발셋.
4. **정함(2026-11-09)**: 판정은 ADR-0054와 같은 규칙으로 한다. 기준은 같은 날 다시 잰 학습 전 모델 × 지금 검색(지금 운영)이고, 운영 선(오답 7/149 이하, 답없음 거절 26/28 이상)과 채택 규칙(오답이나 답없음 거절이 의미 있게 좋아지고, 정답·과잉 거절이 개발셋과 새 평가 데이터 모두에서 의미 있게 나빠지지 않음, 정확 이항 검정 양쪽 p<0.05)을 쓴다. 개발셋을 통과해야 새 평가 데이터를 잰다. 4회차 × 재순위와의 비교는 학습이 바꾼 것을 보는 참고로만 적는다. 학습 전에는 학습 위험 네 가지를 확인한다: 선호 답 결론의 대상 문구가 한 가지 틀로 반복되는지, 거절 쪽 쌍 비율이 실제 실패 비율보다 높은지, 선호·비선호 답의 맞고 틀림을 Claude 판정으로 확인했는지, 학습 입력이 운영과 같은지(재순위 켬·날짜 줄·운영 프롬프트).
   - [원문] 운영 선은 ADR-0033, 채택 규칙은 ADR-0035, 짝 비교는 ADR-0025, 학습 위험 확인은 ADR-0037 변경 메모(2026-10-31)다.
   - [계산] 통과하려면 학습 전 모델의 오답 11개 중 10개 이상을 고치고 새 오답을 2개 이하로 내야 한다(11 대 2는 p=0.023, ADR-0054 실행 전 계산).
   - 버린 대안: 비용 규칙(오답 × k + 과잉 거절, 숫자를 본 뒤 k를 고르면 결과에 맞춘 규칙이 됨 — ADR-0054), 4회차 × 재순위를 기준으로 판정(채택은 지금 사용자가 받는 서비스보다 나은지로 정해야 함).

## 3. 다음(실행 순서)

설계는 여기서 끝나고, 실행은 새 이슈로 한다.

1. 데이터셋용 스택에 재순위 컨테이너를 띄우고 학습 몫 질문에 재순위 근거를 붙인다(결정 1).
2. 학습 질문 200개로 4회차 × 재순위의 실패 답을 받아 실패 쌍 수를 잰다(결정 3). 비슷한 값이 함께 든 질문을 고르는 기준은 이때 코드로 정한다(결정 2).
3. 목표 답(선호 답)을 만들고 Claude 판정과 학습 위험 네 가지를 확인한다(결정 4).
   - 변경(2026-11-09, ADR-0056): 목표 답이 답 탓으로 떨어진 문항은 4회차 답을 목표 답 후보로 판정해 통과한 답을 올린다. 순서는 목표 답 → 자동 검사 → `judge`(목표 답 판정) → `probe --model <4회차>` → `judge --as-target <4회차>` → `judge-probes` → `pairs`다. 시험 묶음에서 Gemma 목표 답이 쉬운 질문만 통과해 쌍이 11개뿐이었다(`5회차-시험-묶음-결과-20261109.md`).
4. 학습 서버를 켜면 #242(4회차 학교 데이터 삭제)부터 하고, 4회차 어댑터에서 이어 DPO를 돌린다.
5. 같은 날 학습 전 모델 × 지금 검색과 5회차 × 재순위를 개발셋으로 재고, 통과하면 새 평가 데이터를 잰다.
