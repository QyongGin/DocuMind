# 표 질문 오답 분석 (2026-11-14)

> 대상: 표 질문 유형 묶음 고르는 몫 47문항을 '같은 표 조각 합치기'(c04, 단계 1에서 거르기를 통과한 유일한 후보)로 잰 실행에서 맞음이 아닌 23문항.
> 측정 기록: `표-근거-실험-단계1-20261114.md`. 이슈 #259.

## 1. 결론

- 23문항 중 9문항은 정답에 필요한 행이나 범례가 프롬프트에 없었다(검색·조립 문제). 14문항은 정답을 받고도 틀렸다(읽기 문제) [실측].
- 받고도 틀린 14문항의 절반 이상이 행·열을 잘못 짚거나 여러 행을 모으지 못한 경우다. 이 오류는 큰 모델에서도 가장 흔한 표 오답이다 [원문, 3절].
- 23문항 가운데 18문항은 지금까지 잰 25개 설정에서 맞음이 두 번 이하였다 [실측]. 프롬프트·청크 모양을 바꾸는 후보로는 거의 움직이지 않는 구조적 오답이다.
- 원인별 처방(4절): 범례 붙이기는 효과가 보여 단계 3 조합에 넣는다. 여러 행을 모으는 질문은 표 전체를 주되 표 질문에만 넓히거나 SQL 경로를 연다. 행·열 오독은 작은 모델에서 프롬프트로 고친 근거가 없어 학습(표 읽기 예시)으로 다룬다. 연도 혼동은 질문의 '작년'을 서버가 학년도로 바꿔 준다.

## 2. 우리 오답 분류 [실측]

방법: 문항마다 챗봇 답, 판정 이유, 프롬프트(모델이 받은 근거 글)를 직접 읽었다. 필수 사실의 값과 정답 행·범례 글이 프롬프트에 있는지 글자로 찾았다(정규화 후 포함 여부). 한 문항에 원인이 둘이면 먼저 막힌 쪽(검색 → 읽기)을 주 원인으로 셌다. 분류는 Claude가 했다.

| 유형 | 문항 수 | 문항 | 실제 예 |
|---|---|---|---|
| 가. 표 일부만 받음(필요한 행이 프롬프트에 없음) | 6 | tq-0001·0008·0024·0033·0034·0036 | ♣ 학과 중 정원 최대: 항공운항과(160) 행이 프롬프트에 없어, 받은 행 중 최대인 건축학과 92를 답함 |
| 나. 범례·주석을 받지 못함 | 3 | tq-0004·0007·0031 | '◈ = 모집인원 제한 없음' 범례가 없어 "◈로 표시돼 인원을 모른다"고 답함 |
| 다. 다른 연도·다른 문서의 값 | 2 | tq-0022·0026 | 2026학년도 41.6이 프롬프트에 있는데 다른 해 표의 35.5를 답함 |
| 라. 받은 표에서 다른 열·다른 표를 읽음 | 5 | tq-0010·0039·0051·0054·0067 | '2022년' 열 대신 바로 앞 '2020년' 열의 12를 답함(정답 7) |
| 마. 여러 행 모으기·비교를 틀림(근거는 다 받음) | 5 | tq-0002·0037·0053·0066·0073 | 100명 넘는 동아리 넷(296·264·151·128명)이 다 있는데 하나만 답함 |
| 바. 답이 있는데 없다고 함 | 1 | tq-0041 | 가스 2등급 실습실 행이 있는데 "정보가 없다"고 거절 |
| 사. 빈칸에 값을 지어냄 | 1 | tq-0030 | 최저 등급 칸이 비었는데 3.3이라고 답함 |

- 가·나(9문항)는 검색·조립 문제, 다~사(14문항)는 읽기 문제다.
- 25개 설정(프롬프트 후보 13, 기준선 2, 표 청크 후보 9, 표 청크 기준선 1)에서 맞음이 두 번 이하인 문항: 18개. 한 번도 못 맞힌 문항: 11개(tq-0008·0024·0026·0030·0031·0033·0036·0041·0051·0054·0073).
- 범례 붙이기는 효과가 보인다: tq-0004는 기준선 세 번(단계 1, 단계 2, 단계 2 다시) 모두 '모름'이었고, 주석 붙이기(기호)와 주석 붙이기(묶음)에서 모두 '맞음'이 됐다. 두 후보 모두 범례 줄이 ◈ 행이 든 청크(모집요강 8·9번)에 붙었다. tq-0031은 붙인 뒤에도 '모름'이다(원인 미확인).
- '표 전체로 넓히기 + 예산'(c13)은 표 질문에서 기준선 대비 좋아짐 5·나빠짐 2였지만, 답없음 거절을 잃은 6문항(ev-0087·0150·0175·0179·0244·0251)은 모두 표와 무관한 질문(기숙사, 등록금 반환, 흡연 장소 등)이다. 넓힌 표가 관련 없는 질문의 근거까지 늘린 부작용이다.

### 2-1. 함께 찾은 채점 결함 [실측]

- 규칙 채점이 금지 값(옆 칸 값, 지난해 값)을 답 전체에서 찾는다. 챗봇이 답 뒤에 근거 표 줄을 옮겨 붙이면, 결론이 맞아도 그 줄에 든 금지 값 때문에 '틀림'이 된다. 예: tq-0047 "조도는 429" + 근거 줄 `|…|397|…|429|`(397이 금지 값).
- 단계 1·2의 모든 실행에서 근거 블록에만 금지 값이 있어 '틀림'이 된 고유 답 8개를 찾아 직접 다시 판정했다: 맞음 3(tq-0047), 일부 2(ev-0104, 결론은 맞고 뒤에서 지난해 값이 맞다고 엇갈림), 틀림 그대로 3. 사람 판정은 규칙이 '애매'로 넘긴 답에만 붙는 구조라, 비교 스크립트에서 '채점결함' 꼬리표 판정으로 덮어썼다.
- 고친 것(#261): 채점기가 답의 줄 가운데 근거 글의 한 줄과 통째로 같은 표 줄을 핵심 사실·금지 값 검사에서 빼고, 핵심 사실이 그 줄에만 있으면 애매로 넘긴다. 위의 덮어쓰기에서 놓친 tq-0047 답(기준선 두 번 포함)도 맞음이 됐다.
- 바뀐 숫자(고친 채점기로 다시 계산): 표 질문 기준선 20 → 21, c04 24(+3, 통과선과 같음), 표 청크 기준선 20 → 21. 거르기 통과 후보는 그대로다(c04, 주석 붙이기(묶음)). c04의 표 질문 정답률 짝 비교(답 있는 43문항): 41.9% → 48.8%, 좋아짐 3·나빠짐 0, 정확 이항 검정 p = 0.25(같은 수준).

## 3. 바깥에서도 같은 문제를 겪었나 [원문]

| 우리 유형 | 바깥 근거 | 어떻게 다뤘나 |
|---|---|---|
| 라. 행·열 오독 | Microsoft·미시간대 MMTU(NeurIPS 2025 Datasets and Benchmarks): o4-mini가 틀린 문항을 LLM으로 분류한 결과 하위 유형 중 "Row/Column index misalignment"가 28.3%로 가장 많다. 사람이 본 분석에서도 표 이해 오류가 38%로 가장 큰 범주다 [1] | 벤치마크 논문이라 처방은 없다. 최신 모델도 같은 오류를 낸다는 근거 |
| 라. 행·열 오독 | EMNLP 2023 [2]: GPT-3.5 오답 표본 50개에서 "errors are mainly caused by incorrect localization of row and column headers" | 표 구조를 먼저 풀어 쓰게 하는 프롬프트. 2023년 모델이라 숫자는 옮기지 않음 |
| 가·마. 표 일부·여러 행 | AWS Bedrock 지식 기반: 표 조각이 검색되면 1만 자 이하인 표 전체로 바꿔 주는 것이 기본 [3]. 정형 데이터는 자연어 질문을 SQL로 바꿔 데이터 저장소에 묻는다 [4] | 표 전체 주기, SQL 경로 |
| 가·마. 표 일부·여러 행 | LongTableBench(Findings of EMNLP 2025): Qwen2.5-7B F1이 관련 부분 검색 20.54, Text-to-SQL 37.42, 표 전체 42.59 [5] | 7B에서는 표 전체 > SQL > 부분 검색 |
| 라·마. 작은 모델의 계산 경로 | TableBench(AAAI 2025): 작은 모델은 코드를 짜서 실행하는 방식에서 크게 나빴다 [5] | 작은 모델에 코드 실행은 비추 |
| 라. 표 읽기 학습 | TAMA(Findings of ACL 2025): LLaMA 3.1 8B에 표 지시 예시 2,600쌍을 학습해 표 과제에서 GPT-3.5·GPT-4와 비슷하거나 나았다 [5] | 학습 |
| 나. 범례 | Azure·AWS Textract·Docling이 표에 캡션·각주를 붙여 준다. 공개 도구는 표 바로 뒤 각주 블록을 붙인다 [6] | 파서가 위치로 붙임 |
| 다. 연도 혼동 | 근거에 옛 판이 섞이면 정답률이 떨어진다. 모델 제작사는 날짜·출처 메타데이터를 보이고 날짜로 거르는 기능을 준다 [7] | 날짜 보이기, 메타데이터로 거르기 |
| 바·사. 거절·지어냄 | Anthropic 공식 문서: 모르면 모른다고 하게 허락하고, 긴 문서는 답 전에 근거를 글자 그대로 먼저 뽑게 한다. 이 방법들이 환각을 "eliminate them entirely" 하지는 못한다고 적었다 [8] | 프롬프트. 우리 인용형 시험은 답 있는 질문을 5번 거절했다 [5] |

- 시니어 개발자 개인 글은 프로젝트 근거 기준(심사 논문, 제작사 공식 문서)에 맞지 않아 찾지 않았다. OpenAI 도움말(스프레드시트는 코드 실행으로 다룬다는 내용)은 페이지가 열리지 않아(403) 원문을 확인하지 못해 뺐다.
