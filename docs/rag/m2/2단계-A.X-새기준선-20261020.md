# M2 2단계 — A.X 새 기준선과 재순위 켬·끔 (2026-10-20)

> 계획: `A.X-기준-계획-20261017.md` §4 2단계. 채택 규칙: ADR-0035(주 지표 = 정답 청크가 근거 8개 안에 든 문항, 정답률·오답률이 의미 있게 나빠지지 않을 것). 기반 모델 결정: ADR-0034.
> 실행(로컬, 커밋 안 함): `Assets/eval/runs/20261020-m2-s2-ax-off`(재순위 끔), `20261020-m2-s2-ax-on`(재순위 켬). 비교 기준 Gemma 실행: `20261016-exp-s3-scores-gemma4-12b`(끔), `20261016-exp-s3-rerank-bge20-gemma4-12b`(켬). 판정 꾸러미 `Assets/eval/work/packets/s2-ax-{off,on}/`, 비교 스크립트 `Assets/eval/work/m2/s2_compare.py`.

## 1. 결론

1. **A.X 기준선(지금 운영 설정, 재순위 끔, 개발셋 본)**: 정답률 76.9%(93/121) · 오답률 6.0%(9/149) · 과잉 거절 7.4% · 답없음 거절 89.3%(25/28) · 출처 정확도 95.9% · 안내 충실도 40.0%(쉬운 문항 52.6%) · 응답 시간 중앙 2.35초. [실측]
2. **같은 설정의 Gemma 4 12B와 비교**: 정답 청크가 근거 8개 안에 든 문항은 둘 다 112로 같아, 차이는 생성에서만 난다. 오답률은 Gemma가 나음(1.3% 대 6.0%, 1 / 8, p=0.039), 쉬운 문항 안내 충실도는 A.X가 나음(28.9% 대 52.6%, p=0.012), 정답률은 같은 수준(83.5% 대 76.9%, p=0.057). 응답은 A.X가 약 1.9배 빠르다(중앙 4.37초 대 2.35초). [실측]
3. **A.X는 개발셋에서 운영 채택의 선(오답률 5% 이하·답없음 거절 90% 이상, ADR-0033)을 아직 조금 넘지 못한다.** 4단계(프롬프트)와 학습이 겨냥하는 몫이다. [실측·판단]
4. **재순위(ADR-0035 판정)**: 주 지표는 112 → 119(0 / 7, p=0.016)로 좋아졌고 정답률은 같은 수준(76.9% → 77.7%)이지만, **오답률이 6.0% → 12.1%(4 / 13, p=0.049)로 의미 있게 나빠져 미채택**이다. 답없음 거절도 89.3% → 67.9%(6 / 0, p=0.031)로 떨어졌다. 판정이 갈릴 수 있는 3건을 빼도 방향은 같다(4 / 10, p=0.18). Gemma에서는 같은 재순위가 오답률을 늘리지 않았다(1.3% → 0.7%). [실측]
5. **GPU**: A.X(문맥 12,288에서 5.2GB) + 임베딩(4.1GB)은 최대 9,731MiB, 재순위 서버까지 켜면 11,365MiB(12,282MiB 중)로 모두 GPU에 올라갔고 강제 종료·메모리 부족이 없었다. Gemma로는 같은 조합이 올라가지 않았다(3단계 보고서 §7). [실측]
6. **발견**: ① compose의 모델 준비 단계가 생성 모델을 Ollama 저장소에서 내려받게 되어 있어, 직접 변환해 등록한 A.X로는 AI 서버가 뜨지 않는다. ② A.X 변환·등록 스크립트와 채팅 틀(Modelfile)이 데스크탑에만 있다. ③ 평가셋 ev-0287(성적향상장학금 기준)은 문서끼리 다르다(FAQ 20%, 장학금지급규정시행세칙 30%). [실측]

## 4. 재순위가 A.X에서 틀린 답을 늘린 모습

- 켬에서 새로 틀린 13건 중 6건이 답 없는 질문이다. 재순위가 질문과 가까운 '비슷하지만 다른 사실'을 맨 위로 올리자 A.X가 그것을 답으로 단정했다[판단]. 예: 2027년 상반기 신청 기간을 묻자 2026년 하반기 기간을 답함(ev-0028), 국가장학금 기한을 묻자 국가근로장학금 공지의 1차 기한을 붙임(ev-0115), 성적표 우편 발송을 묻자 입시 서류 제출 규정으로 '불가능'이라 단정함(ev-0175). [실측]
- 나머지는 표를 잘못 읽거나 계산을 틀린 경우다(연계교육 5명 → 50명, 주차 2,000원 → 2,700원 등). [실측]
- Gemma는 같은 재순위에서 오답률이 늘지 않았다(1.3% → 0.7%). 같은 근거에서 거절할지 판단하는 힘이 모델마다 다르다는 뜻으로 본다[판단]. 4단계의 '근거 줄 인용 → 결론, 없으면 거절' 프롬프트와 학습이 바로 이 실패를 겨냥한다.

## 5. 판정 (ADR-0035)

| 단계 | 주 지표 | 정답률 | 오답률 | 운영 조건(GPU) | 판정 |
|---|---|---|---|---|---|
| 재순위 켬 | 의미 있게 좋아짐(0 / 7, p=0.016) | 같은 수준 | **의미 있게 나빠짐(4 / 13, p=0.049)** | 올라감 | **미채택 — 끄고 4단계 뒤 다시 잼(2026-10-20 사용자 결정)** |

- 판정이 갈릴 수 있는 3건(ev-0002 연도를 잘못 옮김 · ev-0115 다른 장학금의 기한을 붙임 · ev-0166 분할납부 일정을 지어냄)을 틀림에서 빼면 4 / 10(p=0.18)으로 '같은 수준'이 된다. 다만 새로 틀린 13건 중 5건은 규칙 채점이 정한 명백한 틀림이고 방향은 분명하다. 오답률이 가장 엄한 지표(ADR-0026)이고 A.X가 이미 5% 선 위에 있어, 미채택이 맞다고 본다. [판단]
- 4단계(프롬프트)가 거절 판단을 바꾸면 재순위의 득실이 달라질 수 있어, 4단계 뒤 다시 잰다.
- 사용자 결정(2026-10-20): 재순위는 검색에 필요하다고 보고, 단점(비슷하지만 다른 사실로 답을 단정)을 4단계 프롬프트·학습으로 교정할 수 있으면 켠다. 4단계 채택 뒤 같은 설정으로 끔·켬을 다시 재 ADR-0035로 판정한다.
