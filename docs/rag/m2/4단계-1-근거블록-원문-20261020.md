# M2 4단계 ① — 근거 블록에 원문 전체 넣기 (2026-10-20)

> 계획: `A.X-기준-계획-20261017.md` §4 4단계 ①. 채택 규칙: ADR-0035(주 지표 = 정답 사실이 프롬프트 글에 남은 문항, 문맥 기준) — 결과 뒤 보완(같은 ADR의 '보완'). 근거: `청크-임베딩-평가-20261020.md`(발췌 규칙이 정답을 지운 5문항).

## 1. 결론

1. **바꾼 것**: 근거 블록에 표 검색 정보나 질문 의도 추출 정보가 있으면 원문을 빼고 발췌만 넣던 규칙(#110 실험1b, 7.8B 모델용)을 껐다. 이제 원문 전체를 늘 넣고, 발췌·추출 정보는 원문 앞에 그대로 둔다(2026-10-20 사용자 결정). [코드]
2. **주 지표**: 정답 사실이 프롬프트 글에 남은 문항이 112 → 117 / 121(갈린 문항 0 / 5, p=0.0625)로, 늘어난 5문항이 발췌 규칙이 정답을 지웠던 바로 그 5문항이다(ev-0031·0070·0072·0110·0127). 3문항은 맞음이 됐고(0070·0072·0127), 1문항은 그대로 모름, 1문항은 틀림이 됐다(0110). [실측]
3. **답 지표(모두 같은 수준)**: 정답률 76.9% → 81.8%(3 / 9, p=0.15) · 오답률 6.0% → 8.7%(2 / 6, p=0.29) · 답없음 거절 89.3% → 75.0%(4 / 0, p=0.13) · 과잉 거절 7.4% → 4.1% · 출처 정확도 95.9% 같음 · 안내 충실도 40.0% → 44.0%(쉬운 문항 52.6% → 42.1%). [실측]
4. **ADR-0035 판정: ① 단독은 미채택이다.** 주 지표가 p<0.05에 닿지 못했다. 이 변경으로 좋아질 수 있는 문항은 5개뿐이라, 모두 좋아져도 p=0.0625로 처음부터 닿을 수 없는 설계였다(주 지표를 정할 때 계산하지 않음). [계산]
5. **결정(2026-10-20 사용자)**: 기능은 켠 채로 ②(프롬프트 문구)를 그 위에서 재고, ①+②를 한 묶음으로 2단계 기준선과 ②의 주 지표(틀린 답·답없음 거절)로 판정한다(ADR-0035 보완, ② 실행 전에 적음).

## 4. 새로 틀린 답의 모습

- 새로 틀린 6건(ev-0087·0104·0108·0110·0179·0251) 중 3건은 답 없는 질문이다. 원문이 더 들어가자 A.X가 비슷하지만 다른 규정을 끌어와 결론을 단정했다[판단]:
  - 실습실에 밤에 몇 시까지 남을 수 있는지 묻자 현장실습 운영규정(외부 기관 현장실습)의 '오후 10시~오전 6시 운영 불가'로 결론(ev-0087).
  - 자격증 장학금 서류 대리 제출을 묻자 문서 안내(학과사무실 문의)를 인용한 뒤 '일반적으로 대리 제출은 허용되지 않는다'고 단정(ev-0179).
  - 교내 흡연 장소를 묻자 안전진단 보고서의 금연 표지 부착 장소를 흡연 장소로 읽음(ev-0251).
- 나머지는 표 질문이다. 연계교육 5명을 학과 전체 모집 인원으로 읽거나(ev-0108), 특기자(어학) 전형을 묻자 원문이 들어온 교원 초빙 안내의 분야를 답함(ev-0110).
- 재순위를 켰을 때(2단계 보고서 §4)와 같은 실패다: 근거가 늘면 A.X가 거절하지 않고 가까운 다른 사실로 답한다. ② 문구(근거 줄 인용 → 결론, 없으면 거절)가 바로 겨냥한다.
- 틀림에서 벗어난 2건: 푸른등대 합계 1,065명을 맞힘(ev-0091), 표 값을 바르게 읽음(ev-0126).

## 5. 판정 (ADR-0035)

| 단계 | 주 지표 | 정답률 | 오답률 | 운영 조건 | 판정 |
|---|---|---|---|---|---|
| ① 원문 넣기 | 좋은 쪽이지만 의미 있지 않음(0 / 5, p=0.0625) | 같은 수준(좋은 쪽) | 같은 수준(나쁜 쪽) | 잘림 0, GPU 그대로 | **단독 미채택 — 켠 채로 ②와 묶어 판정(2026-10-20 사용자 결정)** |

- 버린 안: 규칙대로 끄고 ②를 발췌 위에서 재기 — 지금 규칙으로는 ①을 다시 재도 통과할 수 없어 사실상 영구 미채택이 되고, 정답 줄을 지우는 결함이 학습 데이터 형식(ADR-0010)에 남는다. 지금 채택 — 오답률 8.7%로 운영되고 결과를 본 뒤 규칙을 어긴다.
- 확신도: 높음(주 지표의 움직임은 코드로 예측한 5문항과 같음), 중간(늘어난 오답이 ②로 줄어드는지). 검증 시점: ② 실행.

## 6. 한계

- 개발셋 본 121·149문항이라 문항 하나가 0.7~0.8%p다. 답 지표 차이는 모두 같은 수준이다.
- 애매 판정은 한 판정자(본 세션)가 했다. ev-0056(곁들인 다른 장학금 기한)은 모름, ev-0150(다른 반환 규정을 안내)은 틀림으로 갈랐다 — 답이 그 값을 질문 대상의 답으로 내세웠는지로 나눴다.
- 주 지표가 처음부터 p<0.05에 닿을 수 없었던 것은 설계 실수다. ADR-0035 보완에 '갈릴 수 있는 최대 문항 수와 가장 작은 p를 먼저 적는다'를 더했다.
