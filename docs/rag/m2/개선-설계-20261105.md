# M2 개선 설계: 검색 탈락과 학습이 만든 실패

> 상태: 1단계 확정(2026-11-05, ADR-0054). 이슈 #235. 바탕은 `4회차-학습-결과-20261105.md`. 결정은 한 번에 하나씩 정해 이 문서와 ADR에 적는다.

## 1. 목표

- 운영 선(ADR-0033): 개발셋 오답 5% 이하(7/149 이하), 답없음 거절 90% 이상(26/28 이상).
- 채택 규칙(ADR-0035): 지금 운영 모델보다 정답률과 과잉 거절이 의미 있게 나빠지지 않는다.
- 지금은 어느 구성도 둘을 함께 맞추지 못한다. 학습 전 모델(운영 중)은 운영 선 미달(오답 11, 답없음 거절 24/28)이고, 학습한 모델(1~4회차)은 운영 선은 넘지만 채택 규칙 미달이다.
- 이 설계의 목표: 운영 선과 채택 규칙을 함께 맞추는 구성을 찾는다.

## 2. 실패 목록

[실측] 개발셋 본 149문항, 2026-11-05 같은 조건(날짜 줄 켬, 기준 날짜 2026-10-31, 근거 8개)으로 잰 학습 전 모델과 4회차 모델.

| 단계 | 실패 | 학습 전 | 4회차 |
|---|---|---:|---:|
| 검색 | 정답 근거가 프롬프트에 없음(답 있는 121문항 중) | 12 | 12 |
| 생성 | 일부만 답함(근거는 프롬프트에 있음) | 6 | 13 |
| 생성 | 근거를 받고도 거절 | 0 | 7 |
| 생성 | 틀림(근거는 프롬프트에 있음) | 5 | 2 |
| 생성 | 답없음 문항(28)에 값을 지어냄 | 4 | 0 |
| | 맞음(답 있는 121문항) | 98 | 87 |

- 검색 단계 12문항은 두 모델이 같은 프롬프트를 받으므로 같다. 이 12문항에서 학습 전 모델은 거절 7·일부 3·틀림 2, 4회차는 거절 10·일부 1·틀림 1이었다.

## 3. 원인 분석

### 3-1. 검색: 정답 청크는 12문항 모두 후보 안에 있었다

[실측] 문항마다 정답 근거 글이 검색 단계별 목록 어디에 있었는지 찾았다(평가 실행 기록의 단계별 후보 목록).

| 유형 | 문항 | 관찰 |
|---|---:|---|
| 순위 밖 | 7 | 벡터 검색 순위 3~16위가 순위를 합친 목록에서 9~21위로 내려가 최종 8개 밖. 7문항 중 5문항은 벡터 13위 안, BM25 후보 8개에는 거의 없음 |
| 근거 블록에서 잘림 | 3 | 정답 청크가 최종 1~2위인데, 근거 블록이 청크 원문 대신 '질문 의도 추출 정보'와 '질문 관련 발췌' 몇 줄만 넣어 정답 문장이 빠짐(청크 길이 423~767자) |
| 분류 재확인 | 2 | 정답 글이 프롬프트에 있었는데 검색 실패로 분류됨. 여러 근거 문항이라 다른 근거가 빠졌을 수 있다 |

### 3-2. 학습이 만든 실패

- [실측] 일부만 답함 13개(4회차): 절차 5·설명 3·예아니오 3·목록 2. 4회차 답 길이 가운데값 157자, 같은 문항 학습 전 모델 답(근거 붙임 제외) 333자. 학습 전 모델은 이 중 9문항을 맞혔다. 학습한 모델이 짧게 답하며 단계·조건을 빠뜨린다.
- [실측] 근거를 받고도 거절: 3회차 학습 예시의 질문 글자 쌍이 근거에 있는 비율은 답 있는 예시 가운데값 0.63(아래 4분위 0.53), 거절 예시 0.50(0.37)이다. 개발셋에서 3회차가 근거를 받고도 거절한 질문은 0.42, 문서와 다른 말로 물은 질문은 0.46(그 외 0.59)이다.
- [판단] 학습 예시에서 '질문 낱말이 근거와 덜 겹치면 거절'이 맞는 경우가 많아, 모델이 근거의 뜻보다 겹침으로 거절을 정하는 지름길을 배웠을 수 있다. 데이터의 우연한 상관을 규칙처럼 배우는 현상은 Geirhos 외, "Shortcut learning in deep neural networks", Nature Machine Intelligence 2, 665–673(2020)이 정리했다. 확신도 중간.

### 3-3. 학습 전 모델의 생성 실패

- [실측] 틀림 5개와 답없음 문항에서 지어낸 4개는 대부분 비슷한 다른 문서나 표의 다른 행 값을 답으로 쓴 경우다(판정 종류 '다른문서사실' 답 있음 5 중 4, 답없음 4 중 3). 학습은 이 실패를 줄였다(4회차 틀림 2, 지어냄 0).

## 4. 전에 버린 검색 개선을 다시 보는 이유

[원문] M2 2·4단계 보고서(학습 전 A.X, 당시 기준선 정답률 76.9%·오답률 6.0%):

| 개선 | 겨냥 | 결과 | 판정 |
|---|---|---|---|
| 근거 블록에 청크 원문 넣기(발췌 끄기, 4단계 ①) | 근거 블록에서 잘린 5문항(이번 3-1과 같은 ev-0031·0070·0072·0110·0127) | 프롬프트에 정답 사실 112 → 117(p=0.0625), 3문항 맞음·1문항 틀림. 정답률 76.9 → 81.8%(p=0.15), 오답률 6.0 → 8.7%(p=0.29), 답없음 거절 89.3 → 75.0%(p=0.13) | 미채택. 좋아질 수 있는 문항이 5개뿐이라 주 지표가 p<0.05에 닿을 수 없었다 |
| 재순위 켜기(bge-reranker-v2-m3, 후보 20) | 순위 밖 | 정답 청크가 근거 8개 안 112 → 119(p=0.016). 오답률 6.0 → 12.1%(p=0.049), 답없음 거절 89.3 → 67.9%(p=0.031) | 미채택. 계획에 "단점이 교정되면 다시 잰다"(`A.X-기준-계획-20261017.md`) |

- [원문] 두 개선이 막힌 이유는 같다. 근거가 늘거나 앞으로 오면 A.X가 거절하지 않고 질문과 가까운 '비슷하지만 다른 사실'로 답을 단정했다(`2단계-A.X-새기준선-20261020.md`, `4단계-1-근거블록-원문-20261020.md`).
- [실측] 학습한 모델은 바로 그 실패를 줄였다. 비슷한 다른 문서의 값으로 단정한 답(판정 종류 '다른문서사실')이 학습 전 8개(답 있음 5·답없음 3)에서 4회차 2개로, 답없음 거절은 24 → 28/28이 됐다.
- [판단] 그래서 두 개선을 학습한 모델과 묶으면, 학습 전 모델에서 막혔던 이유(오답 증가)는 약해지고, 학습한 모델의 약점인 검색 원인 과잉 거절(10개)은 줄 수 있다. 새로 학습하지 않고 데스크탑에서 바로 잴 수 있다. 확신도 중간.

## 5. 개선 후보

### A. 검색 개선 × 학습한 모델(새 학습 없음)

- A1 근거 블록에 청크 원문 넣기: 코드는 `exp/m2-s4-fulltext-context`(AI 서버 5파일, 테스트 포함)에 있다. develop으로 옮겨 설정으로 켜고 끈다.
- A2 재순위 켜기: TEI(`text-embeddings-inference:89-1.9`) + bge-reranker-v2-m3, 후보 20(3단계와 같은 설정, `docs/development/local-gpu/평가-실행-절차.md`). [원문] 정답 청크는 RRF 상위 20 안에 119/121이 있어 재순위로 끌어올릴 여지가 있다.
- 순위 합치기 방식(가중 RRF·보르다·점수 결합)은 오프라인 비교에서 모두 RRF와 같은 수준이었으므로 이번에는 다루지 않는다.

### B. 학습 데이터(5회차를 한다면, A 결과 뒤)

- B1 지름길 없애기: 답 있는 예시 일부를 다른 말 질문(`trainset plan --reword-share`)으로, 거절 예시 일부를 같은 질문의 답없음 사본으로 만든다. 학습 전 검사: 두 종류의 질문·근거 겹침 가운데값 차이 0.05 이내.
- B2 빠짐 없는 목표 답: 절차·목록 목표 답이 근거의 단계·항목을 모두 담는지 자동 검사에 더한다.
- B3 학습 예시의 근거는 A에서 채택한 검색 구성으로 다시 붙인다(근거 모양이 바뀌므로).

### C. 판정 규칙

- C1 지금 규칙(운영 선 + 채택 규칙)을 그대로 쓴다.
- C2 오답 하나와 과잉 거절 하나의 비용을 정해 둘을 함께 보는 규칙으로 바꾼다(ADR-0033 변경). A 결과를 보기 전에 정해야 한다.

## 6. 순서(제안)

1. A: A1을 develop으로 옮김(테스트) → 학습 전·4회차 × {지금, A1, A2, A1+A2} 중 필요한 조합을 같은 날 잼(개발셋 + 새 평가 데이터).
2. A 결과를 판정 규칙(C)으로 판단 → 통과한 구성이 있으면 운영 전환과 테스트셋 1회(ADR-0026).
3. 통과한 구성이 없으면 B(5회차)를 설계한다.

## 7. 결정할 것(한 번에 하나)

1. **정함(2026-11-05)**: 첫 단계로 A를 잰다. 같은 날 학습 전 × 지금 검색, 4회차 × {지금 검색, 원문 넣기, 재순위, 둘 다} 다섯 조합을 개발셋으로 재고, 가장 나은 조합만 새 평가 데이터로 잰다.
2. **정함(2026-11-05)**: 판정은 C1(지금 규칙). C2의 실패 합(k = 1·2·3)은 참고로만 보고한다. 실행 전 계산과 상세는 ADR-0054.
