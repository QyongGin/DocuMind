# M2 학습 4회차 설계: 3회차 모델에 선호 학습(DPO)

> 상태: 설계 확정(2026-11-03), 실행 전. 이슈 #225, 결정 ADR-0053. 1~3회차 결과는 `1회차-학습-결과-20261103.md`, `2회차-학습-결과-20261103.md`, `3회차-학습-결과-20261103.md`.

## 1. 목표와 판정 기준(실행 전 확정)

목표: 1~3회차 학습으로 얻은 오답 감소와 답없음 거절 개선은 지키고, 늘어난 과잉 거절을 학습 전 모델 수준으로 되돌린다.

판정은 운영 채택 규칙(ADR-0033 운영 선, ADR-0035 비교 규칙)을 그대로 쓰고, 새 평가 데이터에서도 악화가 없어야 한다. 비교는 같은 날 다시 잰 학습 전 모델과 같은 문항 짝 비교(정확 이항 검정, ADR-0025).

| 데이터 | 기준 | 3회차 현재 |
|---|---|---|
| 개발셋 149문항 | 오답률 5% 이하 | 5.4%(8/149), 미달 |
| | 답없음 거절 90% 이상 | 92.9%(26/28), 1문항 여유 |
| | 오답률이나 답없음 거절이 학습 전보다 의미 있게 좋아짐 | 둘 다 같은 수준(p=0.39, p=0.38) |
| | 정답률과 과잉 거절이 학습 전보다 의미 있게 나빠지지 않음 | 정답 97 → 87(p=0.031), 과잉 거절 7 → 15(p=0.0078), 악화 |
| 새 평가 데이터 260문항 | 정답률과 과잉 거절이 학습 전보다 의미 있게 나빠지지 않음 | 정답 167 → 168(p=1.0), 과잉 거절 9 → 18(p=0.012), 악화 |

- 통과하면 테스트셋으로 한 번 잰다(ADR-0026). 통과하지 못하면 운영 모델은 학습 전 모델을 유지하고, 다음 진행은 4회차 결과 보고서에서 정한다.
- 함께 보고하는 지표(판정에 쓰지 않음): 표 근거·글 근거 정답률(개발셋 45·76문항, 3회차 62%·78%), 답 길이 가운데값, 거절 머리말 수, 검증 몫의 `rewards/accuracies`.

## 3. 가설과 외부 근거

- H1(과잉 거절): 지도 학습(SFT)은 목표 답을 따라 쓰게 할 뿐, '근거에 답이 있으면 거절하지 않는다'는 신호는 거절 예시 비율로만 간접 전달된다. 3회차가 실제로 낸 거절 답을 비선호 답으로 주는 선호 학습은 거절 기준을 직접 옮긴다. 확신도 중간 [판단].
- H2(표 오독): 3회차가 표의 다른 칸·행 값을 쓴 답을 비선호 답으로 주면 표 근거 오답이 준다. 표를 읽는 능력 자체의 한계일 수 있어 확신도 낮음 [판단].
- [원문] 같은 문제를 같은 방법으로 다룬 심사 통과 연구: Song 외, "Measuring and Enhancing Trustworthiness of LLMs in RAG through Grounded Attributions and Learning to Refuse", ICLR 2025(Singapore University of Technology and Design, DSO National Laboratories). RAG에서 생성 모델의 오류를 "Inaccurate Answers, Over-Responsiveness, Excessive Refusal, Over-Citation, and Improper Citation"으로 나누고, 지도 학습 모델이 낸 오류 답을 비선호 답, 정답 주장과 출처로 만든 답(답이 없으면 거절)을 선호 답으로 "19K samples with paired positive and negative responses"를 만들어 DPO로 학습했다. 결과는 27개 모델·데이터셋 조합 모두에서 "correctly refuse or provide grounded answers" 능력이 좋아졌지만, 답 정확도(F1_AC)는 "mixed effects"(ASQA에서 9개 중 2개 모델만 나아짐)였다.
- 우리 쌍 종류와의 대응: ① 과잉 거절 = Excessive Refusal, ② 틀린 값 = Inaccurate Answers, ③ 지어내기 = Over-Responsiveness. 출처 오류 두 종류는 우리 개발셋에서 문제가 아니어서 넣지 않는다(2절).
- 확인: H1은 개발셋과 새 평가 데이터의 과잉 거절, H2는 표 근거 정답률(보고 지표)로 본다.

## 5. 선호 쌍 데이터

1. 새 질문: `trainset plan → questions → attach → targets → check → judge`로 학습 몫 문서에서 약 600문항을 만든다. 1~3회차에 쓴 문서 묶음은 빼고(`--skip-batches`), 모자라면 같은 문서의 새 질문을 쓴다(2·3회차와 같음). 표 근거 질문은 1~3회차(3회차 22%)보다 늘려 약 40%, 답 없는 질문은 약 30%. 1~3회차 학습 질문은 3회차가 이미 배워 틀린 답이 적게 나오므로 쓰지 않는다 [판단].
2. 3회차 답: `trainset probe`로 문항마다 4번 받는다(온도 0.7, ADR-0042와 같은 설정). DPO 논문 절차도 기준 모델에서 답을 뽑아 쌍을 만든다("Sample completions y1, y2 ∼ π_ref(· | x)", §4).
3. 판정: 자동 검사(값 대조, 거절 문장 유무)로 가르고, 애매한 답만 격리된 Claude 판정(새 평가 데이터와 같은 지시).
4. 쌍 만들기: 문항마다 한 쌍. 선호 답은 판정을 통과한 목표 답, 비선호 답은 3회차 답 중 하나.

| 종류 | 비선호 답(3회차 답) | 선호 답 |
|---|---|---|
| ① 과잉 거절 | 근거에 답이 있는데 거절 문장 | 목표 답 |
| ② 틀린 값 | 표의 다른 칸·행 값, 근거와 다른 값 | 목표 답 |
| ③ 지어내기 | 근거에 답이 없는데 값을 단정 | 거절 안내 목표 답 |
| ④ 거절 머리말 | 거절 문장 뒤에 답 | 목표 답 |

- 한 문항에 해당하는 답이 여럿이면 ①·③ → ② → ④ 순서로 고른다. 3회차가 4번 모두 맞힌 문항은 쓰지 않는다.
- ③ 쌍 수를 ① 쌍 수 이상으로 맞춘다. ①만 많으면 거절 기준이 단정 쪽으로 넘어가 답없음 거절이 떨어진다. 3회차의 개발셋 답없음 거절은 26/28이라 1문항만 더 단정해도 90% 아래로 간다 [판단]. 모자라면 답 없는 질문을 더 만든다.
- 양: 약 200쌍. [계산] 3회차가 온도 0에서 답 있는 문항을 맞히지 못한 비율 27%(새 평가 데이터 63/231)·28%(개발셋 34/121)로 답 있는 질문 420개에서 약 115쌍, 답 없는 질문에서 단정한 비율 7%(개발셋 2/28)~21%(새 평가 데이터 6/29)로 180개에서 13~38쌍. 4번 받으면 더 많다.
- 2026-11-05 변경: 위 방식으로 만든 600문항에서 쌍이 19개뿐이었다. 약 200쌍 계산은 평가 데이터의 오답 비율을 그대로 썼는데, 학습용으로 만든 질문은 평가 질문보다 쉬워 3회차 오류가 훨씬 적었다. 문서와 다른 말로 묻는 질문도 시험했지만 오류가 크게 늘지 않아, 판정을 통과한 답 있는 예시마다 답 근거를 뺀 답없음 사본을 만들어 같은 질문의 '답한다'·'거절한다' 쌍을 짓는다(ADR-0053 변경 메모). 최종 141쌍(지어내기 60, 과잉 거절 60, 틀린 값 20, 거절 머리말 1).
- 검증 몫 10%(종류 비율대로). 반출 범위 검사(학습 몫, 개인정보, 평가 문서와 겹침 0)는 1~3회차와 같다.
- 쌍 30개는 근거 원문과 대조해 판정 오류율을 적는다.

## 6. 평가

- 1~3회차와 같은 조건: 개발셋 149문항(날짜 줄 켬, 기준 날짜 2026-10-31, 근거 8개), 새 평가 데이터 260문항, 같은 날 학습 전 모델을 다시 재어 짝 비교.
- 보고 지표: 표 근거·글 근거 정답률, 답 길이 가운데값(3회차 대비), 거절 머리말 수, 검증 몫 `rewards/accuracies`.

## 7. 학습 위험

| 위험 | 확인과 대응 |
|---|---|
| 거절을 덜 해 지어내기가 늘어남 | ③ ≥ ① 균형. 개발셋·새 평가 데이터 답없음 거절로 확인 |
| 정답률은 그대로일 수 있음 | Trust-Align도 답 정확도는 데이터셋마다 섞였다(3절). 정답률 악화 없음을 판정 기준으로 두고, 오르지 않아도 과잉 거절이 줄면 의미가 있다 |
| 쌍이 적음 | Trust-Align 19K 쌍 대비 약 200쌍. 1회차 지도 학습 200개로도 거절 행동이 크게 바뀐 점[실측]으로 보아 행동을 옮기기에는 충분하다고 보나, 효과가 작으면 쌍을 늘린다 [판단] |
| 답이 길어짐(선호 답이 비선호 답보다 긴 쌍이 많아 길이를 배움) | 답 길이 가운데값을 3회차와 비교. 늘면 `sigmoid_norm`으로 다시 학습([원문] TRL: SimPO의 길이 쏠림 보정, "normalizing by the number of non-mask tokens") |
| 목표 답이나 판정의 오류가 쌍에 들어감 | 선호 답은 판정을 통과한 목표 답만. 30쌍 대조 |
| 3회차 답(온도 0.7)과 운영(온도 0)의 차이 | 평가는 운영 설정(온도 0)으로만 |
| 거절 머리말 버릇이 남음 | ④ 쌍, 거절 머리말 수 보고 |

## 8. 대안과 버린 이유

| 대안 | 버린 이유 |
|---|---|
| 거절 문장 비율을 더 낮춘 지도 학습 | 15.4% → 12.2%에서 과잉 거절 15 → 15 [실측] |
| 반복 늘리기 | 검증 손실이 2번째 반복 뒤 정체 [실측] |
| 거절 안내 예시 모양만 바꾸기 | 3회차에서 거절 머리말이 10 → 3으로 줄었는데 과잉 거절은 15 그대로 [실측] |
| 프롬프트 문구로 고치기 | M2 4단계에서 미채택 [실측]. [원문] Trust-Align: 프롬프트 방법은 모델이 프롬프트에 너무 민감해져 "exaggerated refusals or excessive responsiveness"로 흔들려 효과가 없었다 |
| 학습 전 모델에서 DPO | 목표 답 형식을 배운 3회차가 선호 답 분포에 가깝다(DPO 논문 π_ref = π^SFT). 학습 전 모델은 개발셋 답없음 거절 82%라 ③을 더 많이 배워야 한다 [실측, 판단] |
| 2회차 모델에서 DPO | 새 평가 데이터 정답 159 대 3회차 168, 과잉 거절 22 대 18 [실측] |
| PDF 표를 행 단위 문장으로 색인 | M2 5단계에서 정답 청크 상위 5개 102 → 105(p=0.51)로 미채택 [실측] |
