# M2 학습 3회차 — 2회차 결과를 보고 답 있는 어려운 예시를 더해 다시 학습

> 상태: 끝(2026-11-03). 할지 정하는 규칙은 2회차 결과를 보기 전에 `2회차-학습-결과-20261103.md` 4절에 적었다.

## 1. 결론

- **3회차 모델(`ax40light-r3:q4km`)도 미채택**이다. 개발셋에서 학습 전 모델보다 정답률(80.2% → 71.9%, p=0.031)과 과잉 거절(5.8% → 12.4%, p=0.0078)이 의미 있게 나쁘고, 오답률 5.4%로 운영 선(5% 이하)도 넘지 못했다. 2회차와는 모든 지표가 같은 수준이다. **운영 모델은 학습 전 모델(`ax40light:q4km`) 그대로 둔다.**
- 학습에 안 쓴 문서로 만든 새 평가 데이터(260문항)에서는 세 회차 중 가장 낫다: 정답은 학습 전 모델과 같고(167 → 168), 오답은 의미 있게 줄었다(43 → 27, p=0.011). 과잉 거절은 여전히 의미 있게 많지만(9 → 18, p=0.012) 회차마다 줄었다(1회차 36 → 2회차 22 → 3회차 18). 페르소나 76문항에서도 사용자 입장에서 더 나은 답이 3회차 57, 학습 전 15였다.
- [판단] 데이터 구성(거절 문장 비율)을 바꾸는 방법은 개발셋 과잉 거절을 22 → 15까지 줄인 뒤 멈췄다. 남은 과잉 거절을 줄이려면 데이터의 양이 아니라 거절 안내 예시의 모양이나 학습 방식(예: 답할 수 있는데 거절한 답을 직접 벌주는 선호 학습)을 바꿔야 한다고 본다. 확신도 중간.

## 2. 3회차를 하는 이유

- [실측] 2회차는 학습 전 모델보다 정답률(80.2% → 69.4%, p=0.0044)과 과잉 거절(5.8% → 12.4%, p=0.0078)이 의미 있게 나빠 미채택이다. 2회차 보고서 4절에 결과를 보기 전에 적은 규칙의 첫째 줄(과잉 거절이나 정답률이 학습 전 모델보다 의미 있게 나쁨 → 답 있는 어려운 예시를 더해 다시 학습)에 해당한다.
- [실측] 1회차 → 2회차에서 데이터를 바꾼 효과는 있었다: 과잉 거절 22 → 15(p=0.039). 같은 방향으로 한 번 더 민다.
- [판단] 학습은 2회차 학습이 끝난 07:42에 바로 시작했다(학습 서버가 노는 시간을 줄이려고). 2회차 결과가 규칙상 3회차가 필요 없는 쪽이면 멈추기로 했고, 결과(07:58)가 첫째 줄에 해당해 그대로 이어 갔다.

## 5. 학습 위험

- 거절 머리말 버릇: 2회차에서 늘어난 '거절 문장 + 정답'(3 → 10개)은 거절 안내 예시의 틀에서 왔다고 본다(2회차 보고서 7-1). 3회차도 거절 안내 예시 51개·범위 밖 거절 26개를 그대로 쓰므로 이 버릇은 남을 수 있다. 답 있는 예시가 늘어 비중은 낮아진다(거절 문장이 든 목표 답 15.4% → 12.2%).
- 지어내기: 거절 종류 비중이 11.3% → 9.0%로 낮아져 답없음 문항에서 값을 단정할 위험이 커질 수 있다. 오답률과 답없음 거절을 함께 본다.
- 판정이 놓친 틀린 값: r3-a 판정 탈락의 16개가 '값 틀림'이었다(표 읽기 실수). 통과분에 남은 틀린 값의 비율은 재지 않았다.
- 같은 문서에서 여러 질문: r2-c와 r3-a는 앞 회차에 쓴 문서에서 새 질문을 만들었다. 학교 사실을 외워 근거 없이 답할 위험이 있지만, 평가 문서(개발셋·테스트셋·새 평가 데이터)는 학습 몫과 문서가 겹치지 않아 평가 점수가 부풀지는 않는다.

- 판정: **미채택**. 운영 선의 오답률(5.4% > 5%)도 넘지 못했고, 정답률과 과잉 거절이 학습 전 모델보다 의미 있게 나쁘다.

- 판정한 3회차 틀린 답에는 표의 다른 칸·다른 행을 읽은 경우(대리시험 징계, 최다 선발 장학금 — 학습 전 모델은 맞힘, 취업 회사 — 학습 전 모델도 틀림)와 질문과 다른 사례의 절차를 안내한 경우(주소 변경에 개명 절차 — 학습 전 모델도 틀림)가 있다. 답없음 문항 1개에서는 관계없는 안전표지 글로 '흡연 장소는 없다'고 단정했다(학습 전·1·2회차는 바른 거절).

## 8. 개발셋과 새 평가 데이터가 갈리는 점

- 정답률: 개발셋에서는 세 회차 모두 학습 전 모델보다 의미 있게 낮지만, 새 평가 데이터에서는 2·3회차가 학습 전 모델과 같은 수준이다.
- [판단] 개발셋 149문항은 기준선부터 여러 번 쓴 문항이고, 정답이 사람 검토를 거친 문항이다. 새 평가 데이터는 처음 보는 문항이지만 정답과 판정을 모두 Claude가 했고, 답 있는 문항 중 검색 근거에 정답이 없던 20개가 섞여 있다. 운영 판정은 미리 정한 대로 개발셋 규칙을 따르고, 새 평가 데이터는 방향을 확인하는 데 쓴다. 최종 성공 여부는 한 번도 열지 않은 테스트셋으로 한 번 잰다(ADR-0026).

## 9. 다음

- 운영 모델은 학습 전 모델 그대로 둔다. 학습한 세 모델(`ax40light-r1/r2/r3:q4km`)은 데스크탑에 등록된 채 비교용으로 남긴다. 어댑터와 실행 기록은 데스크탑 `~/incoming/adapters/`에 보관했고, 학습 서버의 학교 데이터(학습 파일·결과·합친 모델·변환 파일)는 지웠다.
- 남은 과잉 거절을 겨냥한 실험 후보는 ① 거절 안내 예시의 모양만 바꿔 다시 학습, ② 같은 질문에 '근거로 답한 답'을 '거절한 답'보다 낫다고 가르치는 선호 학습이었다. ①은 3회차에서 거절 머리말이 10 → 3으로 줄었는데도 과잉 거절이 15 그대로라 버리고, ②를 4회차로 한다(ADR-0053, `4회차-학습-설계-20261103.md`)..
