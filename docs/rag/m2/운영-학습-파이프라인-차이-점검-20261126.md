## 1. 결론

1. 7단계에서 29항목을 견줬다. 22항목이 다르고, 같은 것은 6항목, 해당 없음 1항목이다.
2. 학습 결과를 바꿀 만한 차이는 13항목이다. 영향이 기록으로 확인된 것은 4항목(1차 출처 수와 정답 위치, 2차 표 사실 뺌, 표 블록 본문 모양, 표 크기)이고 9항목은 추측이다.

- 운영 서버 그대로의 프롬프트 모양과 길이: 스택을 띄우지 않았고 `/query`, `/debug/rag-trace`를 부르지 않았다(생성 금지, 조회 범위 밖으로 봄). 그래서 21번의 운영 입력 길이는 측정 프롬프트 값이다.
