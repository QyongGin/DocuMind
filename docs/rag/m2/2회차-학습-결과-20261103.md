# M2 학습 2회차 결과 — 답 있는 어려운 예시를 늘린 데이터로 다시 학습

> 상태: 끝(2026-11-03). 1회차 결과와 계획은 `1회차-학습-결과-20261103.md` 7절, 이어서 한 3회차는 `3회차-학습-결과-20261103.md`.

## 1. 결론

- **2회차 모델(`ax40light-r2:q4km`)도 미채택**이다. 개발셋에서 학습 전 모델보다 정답률(80.2% → 69.4%, p=0.0044)과 과잉 거절(5.8% → 12.4%, p=0.0078)이 의미 있게 나쁘다(ADR-0035). 운영 선(오답률 2.7%, 답없음 거절 100%)은 넘는다.
- 데이터 구성을 바꾼 효과는 있었다: 1회차보다 과잉 거절이 의미 있게 줄었고(22 → 15, p=0.039), 학습에 안 쓴 문서로 만든 새 평가 데이터 260문항에서는 정답률이 학습 전 모델과 같은 수준(167 → 159, p=0.24)이면서 오답이 의미 있게 줄었다(43 → 24, p=0.0013). 1회차는 같은 데이터에서 정답률도 의미 있게 나빴다(167 → 143, p=0.0012).
- 남은 문제는 과잉 거절과 **거절 머리말 버릇**(거절 문장으로 시작하고 뒤에 정답을 붙임, 답 있는 121문항 중 3 → 10개)이다. 결과를 보기 전에 정한 규칙대로 3회차를 했다.

## 4. 3회차를 할지 정하는 규칙(2회차 결과를 보기 전에 적음, 2026-11-03 05:55)

2회차 판정은 1회차와 같다: 운영 선(오답률 5% 이하, 답없음 거절 90% 이상, ADR-0033)과 채택 규칙(학습 전 모델보다 오답률이나 답없음 거절이 의미 있게 좋아지고, 정답률·과잉 거절이 의미 있게 나빠지지 않음, ADR-0035). 3회차는 2회차 개발셋 결과로 아래처럼 정한다.

| 2회차 결과 | 3회차 |
|---|---|
| 과잉 거절이나 정답률이 학습 전 모델보다 의미 있게 나쁨 | 한다. 답 있는 어려운 예시(r3-a)를 더해 거절 비중을 더 낮춘다 |
| 채택 규칙은 넘었지만 정답률이 학습 전 모델보다 나아지지 않음 | 한다. 같은 데이터 보강으로 정답률을 올릴 수 있는지 본다 |
| 오답률이나 답없음 거절이 나빠짐(지어내기 늘어남) | 거절 비중을 낮추는 3회차는 하지 않는다. 원인부터 본다 |
| 모든 지표가 학습 전 모델보다 낫거나 같음 | 하지 않는다(더 나아질 여지를 개발셋으로 확인하기 어려움) |

- r3-a: 답 있는 종류만 420개 계획(표 120, 사실 120, 절차 105, 여러 문서 75), 1·2회차와 같은 방법으로 만들고 Claude 판정을 통과한 것만 쓴다.
- 학습 설정은 2회차와 같게 두되, 반복 횟수는 2회차 검증 손실이 두 번째 반복 뒤 거의 줄지 않으면 2로 줄인다(학습 시간 약 3분의 2). 이때 3회차와 2회차의 차이는 데이터와 반복 횟수 둘이 된다.
- 새 평가 데이터(학습에 안 쓴 평가 몫 문서로 만든 문항, v1 129개 + v2)와 페르소나 질문으로 개발셋 결과를 다시 확인한다. 개발셋은 여러 번 본 문항이라 3회차 판정에 새 평가 데이터를 함께 본다.

### 7-1. 거절이 '거절 머리말'로 옮겨 갔다

[실측] 답 있는 121문항에서 답이 거절 문장으로 시작하는 경우:

| | 학습 전 | 1회차 | 2회차 |
|---|---:|---:|---:|
| 거절 문장만 | 0 | 20 | 10 |
| 거절 문장 + 뒤에 내용(대개 정답) | 0 | 3 | 10 |

- 2회차는 거절 문장만 낸 답을 절반으로 줄였지만, "학교 홈페이지 안내에서 찾지 못했습니다."로 시작한 뒤 정답을 붙이는 답이 3 → 10개로 늘었다. 판정 기준상 '일부'라 정답률이 오르지 않았다.
- [판단] 원인 후보: 학습 파일의 거절 안내 예시(거절 문장 + 문의처·사이트 안내)가 '거절 문장 뒤에 도움이 되는 내용을 붙이는' 틀을 가르친다. 답 있는 종류의 목표 답에는 거절 문장이 하나도 없고(0/581), 일부만 있음 예시 28개 중 첫 문장에 거절이 오는 것은 1개뿐이라, 이 버릇은 거절 안내 예시의 틀에서 왔다고 본다. 확신도 중간 — 같은 데이터에서 거절 안내 예시의 모양만 바꿔 보는 실험으로 확인할 수 있다.

### 7-2. 측정 메모: 같은 질문의 근거가 드물게 달라짐

[실측] 2회차가 받은 프롬프트를 학습 전 모델 것과 글자로 대조했다: 개발셋 205개 중 204개, 새 평가 데이터 v1 129개 전부, 추가 페르소나 22개 전부가 같고, 페르소나 54개 중 3개(P10·P34·P45)와 개발셋 1개가 달랐다. 다른 곳은 내용이 같은 학과별 '오시는 길' 페이지처럼 거의 같은 청크의 순서가 바뀐 것이다(학습 전 모델과 1회차는 같은 시간대에 물어 모두 같았다). 개발셋에서 다른 1개(ev-0244, 답없음)는 학습 전 모델 틀림, 1회차(학습 전 모델과 같은 근거)와 2회차 모두 바른 거절이다. [판단] 답의 맞고 틀림을 바꿀 차이가 아니라 문항을 빼지 않고, 짝 비교 결과와 함께 적어 둔다.


## 8. 결과: 새 평가 데이터와 페르소나

[실측] 새 평가 데이터: 학습에 쓰지 않은 평가 몫 문서로 만든 v1 129문항 + v2 148문항. 정답은 격리된 Claude 세션이 쓰고, 다른 세션이 정답을 보지 않고 다시 답해 핵심 값이 일치한 문항만 남겼다. '답 없음'으로 만든 문항 중 학습 전 모델이 받은 근거에 실제로 답이 있던 17개(정답을 만든 문서 밖에 답이 있음)는 모든 모델에서 뺐다 → 260문항(답 있음 231, 답 없음 29). 모델 답은 격리된 Claude(Opus 5.5)가 정답과 받은 근거를 보고 판정했다. 세 모델이 받은 프롬프트는 문항마다 글자까지 같았다.

| 지표 | 학습 전 | 1회차 | 2회차 | 학습 전 대비 2회차 |
|---|---:|---:|---:|---|
| 오답률(260) | 43 (16.5%, 95% 12.5~21.5) | 19 (7.3%) | 24 (9.2%, 95% 6.3~13.4) | **좋아짐 p=0.0013** |
| 정답률(231) | 167 (72.3%) | 143 (61.9%) | 159 (68.8%) | 같은 수준 p=0.24 |
| 맞음+일부(231) | 193 | 180 | 191 | 같은 수준 p=0.84 |
| 과잉 거절(231) | 9 (3.9%) | 36 (15.6%) | 22 (9.5%) | **나빠짐 p=0.0002** |
| 답없음 거절(29) | 15 (51.7%) | 25 (86.2%) | 23 (79.3%) | **좋아짐 p=0.0078** |

- 답 있는 문항 중 검색 근거에 정답 값이 없던 문항(검색 실패) 20개는 세 모델에 같다(생성 모델 탓이 아님).
- [판단] 학습 전 모델의 오답률이 새 평가 데이터에서 16.5%로 개발셋(8.1%)보다 높다. 정답과 판정을 모두 Claude가 해 판정자 오류가 섞일 수 있고, 검색 실패 문항도 포함한 값이라 모델끼리의 차이로만 읽는다.

[실측] 페르소나 시험(사용자 12가지의 실제 말투 질문 54개 + 영어·검색어형 22개 = 76개, 같은 문서 범위). 격리된 Claude가 두 답을 순서를 섞어(어느 쪽이 학습 모델인지 모르게) 판정했다.
