# 추가 후보 생성 모델 조사 — 13번 비교에 더 넣을 모델 (2026-10-14)

> 목적: 13번 모델 비교의 후보 일곱(A.X 4.0 Light·A.X 3.1 Light·Gemma 4 E4B·Gemma 4 12B·Qwen3-8B·Qwen3-14B·Mi:dm 2.0 Base) 말고 더 넣을 모델이 있는지 찾는다.
> 후보 조건(ADR-0027·0030): ① 학습 서버(A10G 24GB, RAM 16GB)에서 LoRA/QLoRA 학습 가능 ② 라이선스가 학교 공식 챗봇(무료 공개 서비스)과 파인튜닝을 허용 ③ 한국어 능력 근거 ④ 지시 따르기 모델, 문맥 16K 이상 ⑤ 우리 평가(Ollama)에서 돌릴 수 있는 GGUF.
> 조사 방법: Hugging Face 모델 API(`/api/models/<id>`)의 라이선스·파라미터 수, 저장소 LICENSE 파일 첫 줄, 모델 카드·기술 보고서 원문을 직접 열어 확인했다(2026-10-14). 같은 날 서브에이전트가 쓴 초안은 한국 모델을 빠뜨리고 확인되지 않은 정보가 있어 이 문서로 대체한다.

## 1. 결론

**오늘 13번 비교에 두 모델을 더 넣는다** — 둘 다 한국 회사가 만든 7~8B Apache 2.0 모델이고, 같은 방식(기준 실행 프롬프트 그대로, 사고 끔, 온도 0)으로 돌렸다.

| 모델 | 회사 | 크기 | 라이선스(원문 확인) | 문맥 | 한국어 근거(회사 발표) | 우리 평가에 쓴 파일 |
|---|---|---|---|---|---|---|
| Kanana 1.5 8B Instruct (2505) | 카카오 | 8.03B | Apache 2.0 (LICENSE 첫 줄 "Apache License Version 2.0") | 네이티브 32K | KMMLU(0-shot CoT) 48.28 · KoMT-Bench 7.63 | 커뮤니티 GGUF `mradermacher/kanana-1.5-8b-instruct-2505-GGUF` Q4_K_M + Llama 3 채팅 틀을 명시해 Ollama 모델로 만듦 |
| Tri-7B | 트릴리온랩스 | 7.53B | Apache 2.0 (LICENSE·모델 카드 "licensed under the Apache License 2.0") | 32K | KMMLU 51.74 · HAERAE 82.49 · KO-MT-Bench 7.64 · koIFEval 76.63 | 커뮤니티 GGUF `DevQuasar/trillionlabs.Tri-7B-GGUF` Q4_K_M + ChatML 틀(기본 시스템 문장 포함) |

- [계산] 학습 서버 조건: 7~8B는 QLoRA 4비트 가중치 약 5GB + 학습 상태로 A10G 24GB에 여유가 있다(기존 후보 Qwen3-8B·A.X 4.0 Light와 같은 급, `기반모델-후보-상세조사-20261001.md` §9).
- [원문] Kanana 1.5 모델 카드: "Neither the pre-training nor the post-training data includes Kakao user data." 기술 보고서(arXiv 2502.18934, 2025-02)는 한국어·영어 두 언어 모델 계열(2.1B~32.5B)을 설명한다. 초록에 '처음부터 학습'이라는 문구는 없어 계보는 "카카오 자체 개발 계열"로만 적는다.
- [원문] Trillion 7B 기술 보고서(arXiv 2504.15431, 2025-04): "the most token-efficient Korean-centric multilingual LLM available", 학습 토큰 2T 중 다국어 10%. Tri-7B는 그 다음 판(모델 카드).
- [판단] 회사 발표 점수는 평가 설정이 서로 달라 순위에 쓰지 않는다. 우리 평가셋(학교 문서 RAG)으로 직접 잰 결과가 판단 기준이다(ADR-0027).
- [판단] 커뮤니티 GGUF는 공식 배포가 아니다. 서비스로 고르게 되면 학습 단계에서 원본 가중치(safetensors)로 학습·변환하므로 서비스 라이선스는 원본(Apache 2.0)을 따른다. 비교 실행의 양자화(Q4_K_M)는 다른 후보와 같은 수준이다.

## 2. 넣지 않은 모델과 이유

| EXAONE 4.0(1.2B·32B), 4.5 | [원문] LICENSE 첫 줄 "EXAONE AI Model License Agreement 1.2 - NC" — 연구·교육 목적 한정, 학교 공식 서비스 불가(3.5와 같음) | LG가 상업 라이선스를 공개하면 |
