# 학습셋·평가셋을 만드는 최신 실무 — 심사 통과 논문과 모델 제작사 공식 자료 (2026-10-25)

> 목적: M2 6단계(학습 데이터)의 나머지 160개를 만들기 전에, 최근 연구·실무가 학습셋과 평가셋을 어떻게 만드는지 확인하고 우리 방식에서 바꿀 것을 고른다(2026-10-25 사용자 요청: "가장 최근 시점의 근황을 제대로 가져와서 트렌디하게, 효율적으로").
> 자료 기준(AGENTS.md §4, 2026-10-25 사용자 결정): ① 학회·학술지 심사를 통과한 논문, ② 모델을 직접 만드는 회사·기관의 공식 문서·기술 보고서와 라이브러리 공식 문서만 쓴다. 심사 전 프리프린트, 개인 블로그, 업체 글, AI 요약은 쓰지 않는다. 소속·게재처는 원문에서 확인했다.
> 방법: 조사 에이전트 다섯 갈래로 실마리를 모은 뒤, 위 기준에 맞는 것만 본 세션이 원문으로 확인했다. 어느 결정이 어느 자료의 어느 부분을 썼는지는 `README.md`의 참조 지도에 있다.
> 이전 조사: `학습데이터-사람검토-실무조사-20261021.md`, `학습셋-제작-실무조사-20261021.md`(develop).

## 1. 결론

1. 답없음(거절) 예시는 **질문을 만든 뒤 실제 검색 결과에 답이 없는지 확인해 확정**한다. 맞는 행동(답할지 거절할지)은 모델이 받은 문서에 정보가 있느냐로 정해지고, 학습 예시는 실제 앱 입력과 같아야 한다. [원문 1·5·6]
2. 작은 모델을 큰 모델로 가르칠 때 모델 제작사는 **교사 답 따라 쓰기 다음에 학생이 직접 낸 답을 교사가 채점하는 단계(온정책 증류)**를 쓴다. Qwen3 8B에서 강화학습보다 GPU 시간이 약 1/10이면서 점수가 높았다. [원문 2·3]
3. 학생 모델에게 같은 질문을 여러 번 답하게 해 예시마다 아는 정도를 재고 학습 비중을 조절하는 방법이 심사를 통과했다. Anthropic도 같은 질문을 여러 번 돌려 답이 엇갈리면 환각 신호로 본다. [원문 4·5]
4. 판정 모델은 사람 전문가와 맞춰 보정한다. 우리 첫 묶음 30개 대조가 이것이다. [원문 7]
5. 합성 평가셋은 생성 모델 비교에서 순위가 흔들릴 수 있고, 수백 문항보다 작은 평가셋에서 정규근사(CLT) 오차 막대는 너무 좁다. [원문 8·9]

## 4. 한국어

- 한국어 판정 모델과 사람의 일치도를 잰 심사 통과 연구는 찾지 못했다. Claude 판정의 우리 과제 일치도는 첫 묶음 사람 대조로 직접 잰다(ADR-0037 그대로).

## 5. 반영하지 않은 것

- 온정책 증류 그대로: 교사·학생 토크나이저가 달라 토큰 단위 채점이 안 되고, A10G 24GB에 7B 학생과 12B 교사를 함께 올리기 어렵다. [판단]
- Claude 판정 이유를 Gemma에 돌려줘 고쳐 쓰게 하는 반복: 목표 답이 Claude 출력에 기대게 되어 ADR-0010·0040의 'Claude 출력은 학습에 쓰지 않는다'와 부딪칠 수 있다. 자동 검사 결과만 돌려주는 반복은 가능하다. [판단]
- 실제 데이터 20~30%를 섞으라는 권고: 업체 블로그에서 나왔다.
