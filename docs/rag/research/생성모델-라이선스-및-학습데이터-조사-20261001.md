|---|---|---|---|---|

| EXAONE 4.0 (1.2B·32B), 4.5 (33B) | 1.2 - NC | "solely for research and educational purposes" — 예시: evaluation, testing, academic research, experimentation, learning, teaching, training, competitions | **불분명**. 입시·학사 안내 챗봇이 "교육 목적"인지 원문에 없음. 공통 조건 (1.1·1.2 원문):
- 파생 모델: 1.1은 "used exclusively for research purposes", 1.2는 "research and educational purposes". 이름은 "EXAONE"으로 시작.
- 출력 사용: 1.1 "shall not use the Model, Derivatives or Output to develop or improve other models" → **EXAONE 출력으로 다른 모델의 학습 데이터를 만들면 안 된다.** 1.2는 "models that compete with the Licensor's models"로 범위를 좁힘.
- 권리 확보 경로: LG AI Research에 서면 문의. 문의처는 EXAONE 3.5 기술 보고서에 적힌 `contact_us@lgresearch.ai` (에이전트 보고, 원문 PDF는 직접 확인 못 함). 상업 라이선스 조건·가격은 공개돼 있지 않다.

**판단**: LG의 서면 허락 없이 EXAONE을 공식 서비스의 기반 모델로 학습시키는 것은 위험하다.

## 4. 학습 데이터는 얼마나 필요한가

| 근거 | 내용 |
|---|---|
| DPR (Karpukhin et al., 2020) | 검색 모델을 WebQuestions **2,474개**, CuratedTREC **1,125개**(원 데이터 3,417·1,353개 중 학습에 쓴 수)로만 학습해도 상위 20개 검색 정확도가 BM25보다 높았다: WQ 55.0% → 73.2%, TREC 70.9% → 79.8% (논문 표 1·2, 원문 확인) → 천~수천 개 규모로도 검색 개선 가능 |
| LIMA (Zhou et al., 2023) | 잘 고른 1,000개로 LLaMA-65B의 응답 행동을 맞춤 → 행동 교정은 양보다 질 |
| RAFT (Zhang et al., 2024) | 질문 + 정답 문서 + 방해 문서로 학습해 "근거에서 답 찾기"를 가르치는 방법. 논문에 데이터 개수는 명시되지 않음 |

우리 추정 (가정이 들어간 계산):
- 지금 색인은 문서 5개에서 검색용 청크 214개. M1에서 문서를 약 100개 모으고 문서당 20~40개 청크라면 청크 2,000~4,000개.
- 청크당 질문 1~2개를 만들고 중복·품질 검사로 절반을 거르면 **학습용 질문 1,000~4,000개** + "근거에 답이 없는" 거절 예시 1~2할.
- → 위 근거들(1천~2천여 개)과 같은 규모라 **M1에서 넓게 모으면 충분할 가능성이 높다.** 지금 문서 2개만으로는 부족하다(다양성 부족으로 과적합).
- 평가용 문서(예: 2027 모집요강)는 학습에서 뺀다. 나누는 단위는 청크가 아니라 **문서**여야 한다(비슷한 청크가 양쪽에 섞이는 누수 방지).

## 6. 학습 데이터를 무엇으로 만드나 (약관)

| 도구 | 조건 (원문) | 판단 |
|---|---|---|
| EXAONE | 출력으로 다른 모델 개발·개선 금지 (1.1) | **쓰지 않는다** |
| Claude (소비자 약관 3조) | "인공 지능 또는 기계 학습 알고리즘 또는 모델을 개발 또는 훈련하는 것을 포함하여 당사 서비스와 경쟁하는 상품 또는 서비스 개발" 금지 | 학교 챗봇 모델이 "경쟁"인지 해석 문제. 평가셋 초안(학습 아님)은 문제없음 |
| Claude (상업 약관 D.4) | "build a competing product or service, including to train competing AI models" 금지 | 위와 같음 |
| Apache 2.0 오픈 모델 (예: Qwen3.5) | 출력 사용 제한 없음 | **학습 데이터 생성은 AWS에서 오픈 모델로** 하면 약관 문제를 피한다 |

## 7. 결론: "학습시켜 놓고 못 쓰는" 일을 막는 순서

1. **라이선스로 먼저 거른다** (이 문서). 공식 서비스에 쓸 수 있는 후보만 남긴다.
2. **학습 전에 기반 모델을 고른다.** M1 실제 문서 평가셋으로 후보 2~3개(예: A.X 4.0 Light, Mi:dm 2.0, Qwen3.5-9B)를 같은 파이프라인에서 비교한다.
3. **그다음 학습한다.** 학습 데이터는 우리 공개 문서 + 오픈 모델 생성 + 사람 검수, 평가 문서는 학습에서 제외.
- EXAONE을 계속 쓰고 싶다면 1번 전에 LG에 서면 문의한다 (답을 받기 전에는 EXAONE에 학습을 걸지 않는다).

## 9. 확인하지 못한 것

- LG의 공식 입장: 학교가 운영하는 무료 안내 챗봇이 "교육 목적"인지
- EXAONE 상업 라이선스 조건·가격
- AI Hub 데이터 이용 약관
- 후보 모델들의 실제 VRAM 사용량(임베딩과 동시 서빙)과 GGUF 변환 가능 여부 → 데스크탑 실측 필요
- Qwen3.5·Gemma 4의 한국어 성능 → 우리 평가셋으로 측정
