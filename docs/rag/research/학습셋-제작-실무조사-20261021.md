# 근거 기반 답변 학습셋을 만드는 법 — 실무·연구 조사 (2026-10-21)

> 목적: M2 6단계 학습 예시 초안을 만들기 전에, 2025~2026 실무·연구가 근거 기반 답변(RAG, 근거가 없으면 거절) 모델의 학습셋을 어떻게 만드는지 확인하고 우리 계획에 반영할 것을 고른다(2026-10-21 사용자 요청: "거짓 정보는 거르고").
> 방법: 조사 에이전트로 네 갈래(합성 학습 데이터 흐름, 근거 기반 답변 학습 데이터, 질문 만들기·다양성, 품질 거르기)를 모은 뒤, 결정에 쓰는 주장은 본 세션이 원문(arXiv 초록·학회 표기)으로 다시 확인했다. 조사 초안에서 틀린 저자·번호·사용권 설명이 여럿 나와(§5) 확인한 것만 적는다.
> 쓰인 곳: ADR-0039(목표 답 모양), ADR-0040(초안 모델), ADR-0037(검토), `../m2/A.X-기준-계획-20261017.md` §5.

## 1. 결론

1. 데이터를 만든 모델과 판정 모델은 다른 계열로 둔다 — 관련된 판정 모델은 그 데이터로 학습한 모델을 편든다(Preference Leakage). 우리는 Gemma로 만들고 Claude로 판정한다. 평가셋 초안도 Claude가 썼으므로 Claude로 학습 데이터를 만들면 판정과 평가 둘 다 후해진다. [원문 1]
2. 한 번의 프롬프트로 문서마다 질문을 뽑으면 질문이 치우치고 다양하지 않다. 사용자·질문 범주와 비율을 먼저 정하고 범주별로 만든다. [원문 2·3·4]
3. 합성 질문은 사람이 쓴 질문보다 덜 다양하다. 페르소나는 다양성을 높이지만 세부 설정의 이득은 작다 — 사용자 범주는 간단히, 길이·말투를 다양하게 지시하고 만든 뒤 중복을 확인한다. [원문 5]
4. 근거 인용과 거절을 학습시키면 신뢰도 지표가 좋아진다는 근거가 있다(8B 포함). 우리 계획의 거절 예시와 `[출처 N]`을 뒷받침한다. [원문 6]
5. 합성 데이터의 편향은 절대 성능에 크게, 두 시스템의 상대 비교에는 작게 영향을 준다. 학습 전후를 같은 문항 짝 비교로 재는 우리 방식(ADR-0025)이 이 위험을 줄인다. [원문 7]

## 4. 반영하지 않은 것

- 실제 데이터와 합성 데이터를 섞는 비율 권고(예: 80 대 20): 근거로 든 모델 붕괴 연구는 모델 출력으로 세대를 거듭해 다시 학습하는 경우다. 우리 학습 예시는 학교 문서 근거로 한 번 행동을 가르치고, 실제 사용자 질문 기록이 없다.
- 답없음 비율 30%, 같은 계열 판정 편향 50%, 필터링 탈락 20~30%, 처음 100~200개 사람 검수: 조사 초안에 있었으나 원문으로 확인하지 못했다. 답없음 비율은 1회차 결과로 고친다(계획 §5).
- 영어 중심 사실 검증 모델(MiniCheck·HHEM 등): 한국어 성능을 확인한 공개 자료를 찾지 못했다. 우리 자동 검사는 근거 글과의 글자·숫자 대조와 Claude 판정으로 한다.
