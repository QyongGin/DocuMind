# 후보 모델을 학교 공식 챗봇으로 써도 되는가 — 심층 조사 (2026-10-14)

> 목적: 일곱 후보 모델(A.X 4.0 Light, A.X 3.1 Light, Gemma 4 E4B, Gemma 4 12B, Qwen3-8B, Qwen3-14B, Mi:dm 2.0 Base)이 학교 공식 서비스에 쓸 수 있는지 라이선스·법·규제·안전성으로 확인한다.
>
> 방법: 이전 문서(`후보모델-학교챗봇-사용가능-재확인-20261013.md`, `생성모델-라이선스-및-학습데이터-조사-20261001.md`, `A안-후보모델-심층조사-20261001.md`)에서 확인한 내용(라이선스, AI 기본법 기본)을 인용하고, 미확인 부분(EXAONE 후속 판, 개인정보보호위 가이드 최신, 중국 계보 모델 규제, 각 모델의 학습 데이터·안전성)을 웹 검색과 공식 문서로 보충했다. 한국 법령은 국가법령정보센터·정부 공식 발표 자료를 기준으로 했다.
>
> 2026-10-14 본 세션 재확인: 라이선스는 Hugging Face API·LICENSE 파일 첫 줄로 다시 확인했고(EXAONE 4.0 'NC' 확정, Kanana 1.5 8B·Tri-7B 추가), AI 기본법 과태료 금액·계도기간은 정부 발표를 옮긴 언론·법무법인 자료(2차 자료)로만 확인했다 — 학교 법무 검토 때 법령 원문으로 다시 본다.
>
> **법률 자문이 아니다.** 해석이 갈리거나 확신이 낮은 부분은 학교 법무·정보보호 담당에게 문의할 질문으로 표시했다.

## 3. 한국 법·규제

### 3.1 인공지능 기본법 제31조 (투명성 의무)

**상태**: 2026-01-22 시행, 시행령 제23조 (2026-08-20 시행본)

| 항목 | 규정 | 우리 챗봇에 영향 |
|---|---|---|
| **사전 고지** (제31조 ①) | 생성형 AI를 이용한 서비스임을 이용자에게 **사전에 고지** | 채팅 시작 전에 "AI가 답변합니다" 안내 + 이용약관에 명시. 위반 시 시정명령, 불이행 시 3천만원 이하 과태료로 정리한 2차 자료가 있음(계도기간 1년 이상, 종료일 미정 — 법령 원문 확인 필요) |
| **생성 표시** (제31조 ②) | 결과물이 생성형 AI로 **생성되었다는 사실을 표시** | 각 답변(또는 서비스 화면)에 생성형 AI 결과물임을 표시. 과태료 적용 범위는 2차 자료끼리 달라 법령 원문으로 확인 필요 — 우리는 표시를 기본으로 넣는다 |
| **딥페이크 표시** (제31조 ③) | 가짜 음성·이미지·영상은 특별 표시 | 우리 챗봇은 텍스트만이라 미적용 |
| **고지 방법** (시행령 제23조) | 이용약관·이용자 화면·장소 게시 등 선택 가능 | 채팅 화면 표시 + 이용약관 기재로 충족 |
| **예외** (시행령 제23조 ④) | 서비스 이름·화면·결과물 문구로 AI 활용이 명백한 경우 예외 | "챗봇" 이름만으로는 충분하지 않음 — 명시적 안내 텍스트 필요 |

**설계 반영 예시**: 채팅 화면 맨 위에 "인공지능(AI)으로 만든 학교 안내 챗봇입니다" + 답변 마다 "(AI 생성)" 배지 또는 문구

**확신도**: 높음 (법령 원문 확인, 현재 계도기간)

### 3.2 중국산 AI에 대한 정부 조치

#### A. 2025년 2월 국가정보원 보안 유의 권고

[원문] 국정원은 **2025년 2월 9일** 딥시크(DeepSeek) 기술 검증 결과를 발표하고, 정부 부처에 생성형 AI 업무 활용 시 보안에 유의하도록 공문을 배포했습니다.

| 문제점 | 구체적 내용 | 우리 후보(Qwen 계) 관련성 |
|---|---|---|
| **개인정보 해외 이전** | 딥시크는 입력 데이터와 개인정보를 중국 내 서버에 저장하며, 중국 법률에 따라 중국 정부 요청 시 제공 가능 | 우리 모델은 **학교 서버 안에서만 실행**되므로 데이터가 나가지 않음. 단 클라우드 운영(ADR-0030)으로 바뀌면 클라우드 리전(국내 조건)을 명시해야 함 |
| **학습 데이터 활용** | 사용자의 모든 입력을 학습 데이터로 활용하며 거부 기능 없음 | 우리는 학교 공개 문서만 학습하고, 사용자 질문은 저장하지 않는 설정으로 회피 가능 |
| **제3자 정보 공유** | 광고주 등과 사용자 정보 제한 없이 공유 | 우리는 서비스 제공자가 아니므로 해당 없음(학교가 직접 운영) |
| **언어별 차등 답변** | "김치 원산지" 등 민감한 질문에 중국어로만 "원산지는 중국"이라 답변 — 같은 질문에 챗GPT 등은 일관되게 답함 | 우리는 한국 학교 문서에 기반하므로 편향 없음. 기반 문서에서 답이 없으면 거절 |

#### B. 후속 정부 조치

[원문] 국정원 권고 이후 정부 부처들의 조치:
- 외교부·국방부·산업통상자원부: 딥시크 접속 차단
- 공정거래위: 개인정보 처리 방침 확인 시까지 접속 차단
- 교육부·고용노동부·행정안전부: 내부 공문으로 보안 유의 안내 (차단 아님)

→ **공공기관 중에서도 부처마다 대응이 다름.** 학교는 교육부 범주이고, 교육부는 차단이 아니라 유의 권고만 했다.

#### C. 규제 대상과 우리 구성

[판단] 정부 조치의 핵심 우려는 **"개인정보가 중국 서버로 나가는 인터넷 서비스"**다. 우리 구성은:
- 공개 모델 가중치를 학교 서버 또는 클라우드(국내 리전)에 설치 → **데이터가 중국으로 나가지 않음**
- 따라서 국정원이 지적한 보안 우려(개인정보 이전, 학습 활용, 언어별 편향)가 발생하지 않음

[원문] "공개 모델 가중치를 학교 서버에 설치해 쓰는 것을 금지하거나 제한하는 정부 규정은 찾지 못했다" (이전 문서 A안-심층조사 §3.2)

**확신도**: 중간 (규정은 없으나, 학교 법무·정보보호 담당이 독자 판단할 사항)

### 3.3 고영향 AI 해당 여부

[원문] AI 기본법 제2조 4호 — 고영향 AI는 권리·의무에 중대한 영향을 주는 AI로, 교육 분야는 **"유아교육·초등교육 및 중등교육에서의 학생 평가"만** 해당. 다른 분야(대학 입시·학사 안내)는 목록에 없다.

→ 우리 챗봇(대학 안내)은 고영향 AI가 아니므로, 추가 신뢰성 평가·감시 의무가 생기지 않는다.

**확신도**: 높음 (법령 원문, 차목 문구 명확)

[원문] SKT GitHub(`SKT-AI/A.X-4.0`)에 따르면:
- A.X 4.0 Light는 Qwen2.5 본체에 한국어 42% + 영어 51% + 기타 7% 추가 사전 학습
- A.X 3.1 Light는 SKT가 처음부터 1.65조 토큰으로 학습
- 둘 다 RLHF 단계를 거침

학습 데이터의 투명성이나 안전 평가 세부는 공개되지 않음.

**우리 평가셋 실측이 최종 기준** (벤치마크 점수는 설정·데이터셋마다 다름)

### 4.2 Gemma 4 (Google)

[원문] Google 기술 보고서와 개발 블로그:
- Gemma 4는 Gemini 모델과 같은 엄격한 안전성 평가를 거침
- 위험 평가: 개방형 AI의 이점을 유지하되, 악용 위험을 지속 평가
- 안전 도구: ShieldGemma 2로 입출력 필터링 제공

**학습 데이터 세부**(출처, 필터링 기준, 개인정보 제거 방식)는 공개되지 않음. 구글은 OpenAI·Anthropic처럼 최근 모델의 학습 데이터 세부를 더 이상 공개하지 않는다는 평가.

**우리 평가셋 실측 필요**

### 4.3 Qwen3, Qwen3-14B (Alibaba)

[원문] Alibaba 공식 설명:
- 36조 토큰, 119개 언어(Qwen3)·201개 언어(Qwen3.5) 사전 학습
- 데이터 출처: 웹 크롤링, PDF 문서(Qwen2.5-VL 처리), 합성 데이터(Qwen2.5-Math·Coder로 생성)
- 사후 학습 4단계: 지도학습(SFT) → 선호도 최적화 → 강화학습(RL) → 안전 정렬

**안전 도구**: Qwen3Guard(0.6B~8B)로 악용 탐지, Apache 2.0 공개. 한국어는 119개 언어에 포함되어 있지만, 독립 평가 점수는 이전 문서(A안-심층조사 §4.2 표)의 비사고 모드 수치로 판단.

**한계**:
- [판단] 중국계 모델의 학습 데이터에 검열이 포함되었을 가능성이 있다는 평가가 있으나, 근거가 명확하지 않음
- Qwen3Guard의 안전 평가는 주로 영어로 제공되어 한국어 성능 검증 필요

**우리 평가셋 실측 필수**

### 4.4 Mi:dm 2.0 Base (KT)

[판단] 모델 카드에 "8B급 모델을 층 확장"이라고만 적혀 있고, 그 8B 모델의 정체와 추가 학습 데이터는 공개되지 않음. 순수 국산 여부를 확인하지 못했다.

안전 평가 기록도 찾지 못함.

**우리 평가셋 실측으로만 판단 가능**

## 6. 학교에 물어야 할 질문 (법무·정보보호 담당)

### A. 법·규제 관련

1. **AI 기본법 제31조 고지·표시 방식**: "AI가 답변합니다" + 각 답변에 생성 표시면 충분한가? 이용약관 기재의 위치와 문언은?
2. **클라우드 운영 시 개인정보 이전**: ADR-0030에서 클라우드에서 운영할 예정인데, 국내 리전 조건만으로 국정원 권고사항(중국 계보 모델 보안 유의)을 충족하는가?
3. **사용자 질문 기록 처리**: 학교가 사용자 질문을 저장하지 않으면 개인정보보호법 적용 범위가 줄어드나? (개인정보위 2025년 안내서 확인 필요)
4. **제3자 AI 제공사와의 계약**: 모델 가중치를 학교에 넘기는 시점(파인튜닝 후 배포)에 어떤 계약·문서(라이선스 사본, 모델 카드)를 남겨야 하나?

### B. 중국 계보 모델 관련 (조직 차원 의사결정)

5. **학교 정책 확인**: 교육부·학교 정보보호 정책에 중국 계보 모델 사용 제한이 있나? (교육부는 2025년 딥시크 대응에서 "유의 권고"만 했으므로, 학교 자체 정책 확인 필요)
6. **제안서 설명 방식**: Qwen 기반 모델의 경우 "중국 모델 기반"을 제안서에서 어떻게 설명할 것인가? (국산 A.X 3.1 Light, Gemma 4, Mi:dm 2.0 Base 중 선택하는 방안도 고려)

### C. 기술 검증 (M1 종료 후)

7. **학습 단계 메모리 확인**: Mi:dm 2.0 Base(11.5B)와 Qwen3-14B를 고르는 경우, 학습 뒤 병합 시 RAM 16GB(AWS g5.xlarge)로 충분한가? (실측 필요)
8. **클라우드 성능 재측정**: 운영 환경이 정해지면(클라우드 제공사·GPU 크기), M2 학습 단계와 M4 운영 준비에서 응답 속도와 VRAM 사용량을 재측정해야 하나?
