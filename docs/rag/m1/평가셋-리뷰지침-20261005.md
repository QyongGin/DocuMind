# 평가셋 리뷰 지침 (리뷰어용)

> 상태: 초안(2026-10-05). 첫 30문항 리뷰 뒤 다듬는다(결정 ④). 결정 ⑦로 리뷰어는 **휴먼 리뷰 대상만(약 100)** 본다.
> 대상: 사용자(전수 리뷰). Claude 초안도 §4 규칙을 지킨다. 예시는 모두 합성(가나대학)이다.
> 리뷰 화면에 §1의 여섯 가지와 §2의 판정 넷이 그대로 나온다. 칸 이름은 `평가셋-파일형식-20261005.md`.

## 0. 이 문항이 왜 왔나 (결정 ⑦)

리뷰 화면에는 아래 넷 중 하나로 온 문항만 나온다. 나머지는 자동 검증과 이중 라벨링을 통과해 자동 승인됐다.

| 온 이유 | 무엇을 먼저 보나 |
|---|---|
| 불일치 | 이중 라벨링 모델이 원본을 다르게 읽은 값. 정답과 이중 라벨링 중 어느 쪽이 원문과 맞나 |
| 테스트셋 답없음 | 부재 확인 기록과 가까운 문서. 정말 답이 없나 |
| 경고 | 부재 확인에 걸린 글, 자동 검증이 남긴 경고 |
| 표본 | 자동 승인이 맞았는지 재는 무작위 문항. 평소처럼 여섯 가지를 본다 |

## 1. 한 문항에서 볼 것 여섯 가지

1. **질문** — 실제로 물을 법한 말인가. 질문만 보고 답이 하나로 정해지나(학년도·학기·학과·전형이 빠져 답이 여럿이면 고침).
2. **정답 = 근거** — 정답 문장과 필수 사실의 숫자·날짜·단위가 인용과 글자 그대로 맞나. 인용 앞뒤 글도 같은 뜻인가.
3. **허용 표기** — 같은 값을 다르게 쓰는 말이 들어 있나(3만 원 / 30,000원, 9.8.(월) / 9월 8일).
4. **금지 값** — 정말 틀린 값인가(지난해 값·옆 칸 값·다른 학과 값). 맞는 값을 금지하지 않았나.
5. **모양·태그** — 모양은 하나. 태그는 근거(표/글)가 맞는지부터 본다.
6. **답 없는 문항** — 부재 확인 기록이 있나. 가까운 문서를 훑어봐도 정말 답이 없나.

## 2. 판정 넷

| 판정 | 언제 | 남길 것 |
|---|---|---|
| 승인 | 여섯 가지가 모두 맞다 | 없음 |
| 고침 | 고치면 쓸 수 있다 | 고친 칸은 화면이 자동 기록. 왜 고쳤는지 한 줄 |
| 버림 | 고쳐도 못 쓴다 | 이유: `근거불일치` · `답여럿` · `바뀌지않는값` · `개인정보` · `중복` · `시점지남` · `기타` |
| 보류 | 판단이 서지 않는다 | 묻고 싶은 것 한 줄(Claude가 답한 뒤 다시 판정) |

## 3. 판정 예시 (합성)

| # | 문항 | 문제 | 판정 |
|---|---|---|---|
| 1 | "가나대 원서비 얼마예요?" · 값 · 정답 30,000원 · 인용 "전형료 30,000원" · 허용 3만 원 · 금지 25,000원(지난해) | 없음 | 승인 |
| 2 | "1차 접수 언제 시작해요?" · 정답 "9월 8일" · 인용 "9.8.(월)" | 허용 표기에 "9.8" 없음 | 고침(허용에 "9.8", "9.8.(월)" 추가) |
| 3 | "수시 접수 언제예요?" | 수시 1차·2차 기간이 달라 답이 둘 | 고침(질문을 "수시 1차 원서 접수는 언제예요?"로) |
| 4 | "가나대 원서비 얼마예요?" · 정답 30,000원 · 인용 "전형료 25,000원" | 정답이 근거와 다름 | 버림(`근거불일치`) |

| 7 | "가나대 2028학년도 정원 몇 명이에요?" · 거절(가까운 빈칸) · 부재 확인 0건 · 가까운 문서 2027 모집요강 | 없음 | 승인 |
| 8 | "기숙사 식비는 얼마예요?" · 거절 · 부재 확인에서 생활관 안내가 걸림 | 실제로는 답이 있음 | 버림(`기타: 답 있음`) |

## 4. 초안 규칙 (Claude가 지키고, 리뷰어가 확인)

- **말투**: FAQ처럼 짧게. 실제 사용자는 학교 이름·학년도를 자주 빼므로, 빼도 답이 하나일 때만 뺀다.
- **한 질문 한 답**: 답이 여럿이 되지 않게 학년도·학기·학과·전형을 질문에 넣는다.
- **인용**: 색인 원문 글자 그대로, 필수 사실이 들어가는 가장 짧은 범위.
- **바뀌는 값만**: 해마다 반복되는 공지와 학과 공통 교양 표는 해마다·학과마다 바뀌는 값만 묻는다.
- **개인정보**: 이름·학번·전화번호로 보이는 글자는 질문·정답·인용에 쓰지 않는다.
- **근거 문서**: 평가 몫이고 서비스 색인에 있는 문서만. `[평가질문제외]` 7개와 글 100자 미만 14개는 쓰지 않는다.
- **문서당 상한**: 10문항 이하(2027 모집요강 40, 안전진단 PDF 10).
- **답 없는 문항**: 답 있는 문항과 같은 주제·말투. 학교와 무관한 질문은 5개 이하.
- **쉬운 문항**: FAQ 쪽마다 하나, 제목 낱말을 그대로 쓴 질문.

## 5. 시간 재기

리뷰 화면이 문항마다 걸린 초를 자동으로 기록한다. 첫 30문항의 중앙값으로 전체 리뷰 시간을 다시 계산한다. 가정(문항당 2분)의 2배 이상이면 테스트셋 100은 지키고 개발용부터 줄인다(결정 ⑥).
