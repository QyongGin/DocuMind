# 13번 기반 모델 비교 — 같은 프롬프트로 생성 모델만 바꿔 재고, ADR-0027 순서로 고른다 (이슈 #130) — 2026-10-14

> 학교 공식 챗봇의 생성 모델(학습 전 기반 모델)을 고르기 위해, 베이스라인 실행에 기록된 프롬프트를 후보 모델 아홉에 그대로 넣어 답만 다시 받고(생성만 다시 돌리기), 평가셋 v3로 채점·판정한 뒤 ADR-0027 순서(오답 거르기 → 정답률 → 같은 수준이면 한국어 지문 읽기)로 골랐다. 이어서 상위 두 모델을 M2에서 쓸 검색(순위 융합)의 프롬프트로 다시 재서(E3) 최종 순서를 정했다.
> 관련: ADR-0004·0025·0027·0029·0030, `docs/rag/research/후보모델-공식챗봇-사용가능-심층조사-20261014.md`(라이선스), `docs/rag/research/추가후보모델-조사-20261014.md`(Kanana·Tri 추가), `docs/development/local-gpu/평가-실행-절차.md` §6-1

## 1. 결론

- **1순위 Gemma 4 12B, 2순위 A.X 4.0 Light**(ADR-0031 제안). [실측]
  - 13번(지금 운영 검색의 프롬프트, 본 250문항): ADR-0027 순서대로 오답 거르기에서 넷이 빠지고(Gemma 4 E4B·Qwen3-8B·Mi:dm 2.0 Base·Tri-7B), 정답률 1위 Gemma 4 12B와 같은 수준인 A.X 4.0 Light가 남았고, 4단계 한국어 지문 읽기(KorQuAD 1.0)에서 A.X 4.0 Light가 정확 일치로 높았다(EM 78.2 대 74.2, p=0.038).
  - E3(M2에서 쓸 순위 융합 검색의 프롬프트, 개발셋): 같은 순서의 2단계에서 A.X 4.0 Light가 빠졌다 — 오답 10 대 1(p=0.012), 오답률 6.7% 대 0.7%. 정답률은 같은 수준(71.1% 대 74.4%, p=0.48).
  - 모델은 앞으로 받을 프롬프트로 골라야 하므로 E3 결과를 따른다(§6, ADR-0031 '버린 대안').
- 두 모델 모두 검색을 순위 융합으로 바꾸면 개발셋 본 정답률이 크게 오른다(A.X 4.0 Light 48.8% → 71.1%, Gemma 4 12B 53.7% → 74.4%, 둘 다 p<0.001). 모델을 바꿔 얻는 폭(13번, EXAONE 대비 최대 +10%p)보다 검색을 고쳐 얻는 폭이 크다. [실측]
- 대가: Gemma 4 12B는 데스크탑 12GB에서 A.X 4.0 Light보다 생성이 약 2배 느리고(46.8 대 86.3토큰/초), 과잉 거절이 더 많다(개발셋 19.0% 대 11.6%, p=0.012). [실측]

### 판정 방식을 바꾼 이유 [실측]

처음에는 서브에이전트 둘이 따로 판정하고 갈린 것만 본 세션이 정하려 했다(2026-10-13 방식). A.X 4.0 Light에서 두 판정이 63건 중 37건(59%) 갈렸고, 갈림의 대부분은 체계적 편향이었다(한쪽은 답을 못 한 경우까지 '틀림', 다른 쪽은 틀린 단정까지 '모름'). 두 판정이 '같다'고 한 26건 중 3건도 틀린 판정이었다(예: 문서의 '7일주전'을 '7주 전'으로 답한 것을 둘 다 맞음). 그래서 이후 모델은 본 세션이 애매 문항을 모두 직접 판정했고, 판정마다 이유를 남겼다. 지침에 오늘 정한 기준을 더했다: 답을 못 함(모름)과 틀린 단정(틀림)을 가름, 답 없는 문항에 '없다·안 된다'를 단정해도 틀림, 문서 숫자·단위를 바꾸면 틀림.

## 6. 검색을 바꾼 프롬프트로 다시 재기 (E3)

13번의 순서는 지금 운영 검색(사람이 만든 규칙 경로)의 프롬프트로 정했다. M2 1단계(ADR-0032 제안)에서 그 검색을 순위 융합으로 바꾸므로, 상위 두 모델을 새 프롬프트로 다시 쟀다.

- 방법 [실측]: M2 실험 E1(EXAONE + 순위 융합 상위 5개, 개발셋 205문항)에 기록된 프롬프트를 두 모델에 그대로 넣었다(생성만 다시 돌리기, 사고 끔·온도 0, 문맥은 모델 토크나이저로 잰 최대 프롬프트 + 512: A.X 4.0 Light 5,632 · Gemma 4 12B 7,168, 프롬프트 잘림 0·실패 0). 2026-10-14 04:50~05:10 데스크탑. 애매는 본 세션이 전수 판정(A.X 36건, Gemma 16건).
- 테스트셋은 묻지 않았다(M2 반복 실험은 개발셋만, ADR-0018).

- A.X 4.0 Light의 틀림 10건 중 7건은 문맥에 있는 표·글을 잘못 읽은 것이고 3건은 근거 없이 답한 것이다(2026-10-15 실행 기록으로 다시 나눔, `docs/rag/m2/모델선정-비교계획-20261015.md` §3). 잘못 읽은 예: 주차 요금 2,000원 → 1,000원으로 계산, 선발 인원 1,065명 → 일부 장학금만 더한 153명, 연계교육 5명 → 47명, 징계 '유기·무기정학' → '무기정학·퇴학', 최다 선발 장학금을 다른 행으로, 대학생 성적 기준에 고등학생 내신 등급 등. 근거 없이 답한 3건 중 하나는 답없는 문항에 다른 규정(자퇴·휴학 반환)을 붙인 것이다. - 과잉 거절은 A.X 4.0 Light가 낮다. Gemma 4 12B만 거절한 10문항 중 A.X 4.0 Light가 맞힌 것도 있다(예: ev-0065 홍보대사 학년). 거절은 '틀린 답'보다 덜 해롭고(ADR-0026이 오답률을 가장 엄하게 봄), M2 5단계(답할지 판단 프롬프트)가 맡는 몫이다. [판단]
