# ADR-0017: 평가셋 형식과 채점

- 상태: 채택
- 날짜: 2026-10-04
- 관련: 이슈 #129, `docs/rag/m1/평가셋-설계-20261004.md` 결정 ①~④

## 맥락

예전 평가셋은 합성 문서·키워드 포함 채점·답 없는 문항 1개뿐이라 학교에 낼 수치가 못 됐다.

## 결정

- 문항마다 답 유형(answer type) 하나(값·목록·절차·예/아니오·설명·답 없음) + 집계용 태그 여러 개(근거 표/글, 해마다 바뀜/연도 시험, 다른 말/FAQ 제목, 조건/비교·계산/여러 근거).
- 정답(ground truth)은 정답 문장 + 필수 사실(허용 표기 여러 개) + 금지 값(지난해 값·옆 칸 값)으로 적는다. 규칙 기반 채점이 맞음·일부·모름·틀림을 매기고, 정하지 못한 "애매"만 사람이 판정한다. 답 속 숫자가 받은 근거에 없으면 지어낸 숫자로 표시한다.
- 근거는 대장 ID + 인용 글로 적고, 검색 단계마다 확인해 실패 위치(검색 실패·후보 탈락·생성 실패·외운 답 의심)를 붙인다.
- 답 없는 문항(unanswerable): 가까운 빈칸·잘못된 전제를 주로, 답 있는 문항과 같은 말투로 쓴다. 서비스 색인 전체 검색 + 검색 기록의 두 겹으로 "없음"을 확인한다. 문서 밖 일반 지식으로 답하면 틀림.
- 평가셋 파일은 `Assets/eval/`(git 제외)의 JSONL 하나. 휴먼 리뷰 전에 자동 검증(인용 일치, 필수 사실 포함, 평가 몫 문서, 중복, 부재 기록)을 하고, 리뷰가 끝나면 버전 + SHA-256으로 고정(freeze)한다.

## 버린 대안

- 낱말 포함 채점: "1992년"·"65학점" 가짜 실패, 모름과 틀림을 가르지 못함.
- LLM 판정 모델만: 판정이 흔들리고 GPU·외부 전송 문제. 사람 판정이 쌓인 뒤 일치율을 재서 정한다.
- 엑셀 왕복: 일부 값이 날짜로 바뀐다.

## 근거

- [원문] CRAG(Meta, 2024): 유형은 문항마다 하나, 정확 일치 → 판정 모델 두 단계, 모름을 틀림보다 낫게 친다.
- [원문] SQuAD 2.0: 답 없는 질문은 답 있는 질문과 비슷해 보이게 써야 한다.
