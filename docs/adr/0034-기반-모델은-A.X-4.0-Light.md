# ADR-0034: 학습하고 운영할 기반 모델은 A.X 4.0 Light — 약점인 틀린 답은 프롬프트와 학습으로 줄인다

- 상태: 채택
- 날짜: 2026-10-17
- 관련: ADR-0031(대체), ADR-0026·0027·0030·0033, `docs/rag/m2/모델선정-비교계획-20261015.md`(대체), `docs/rag/research/A.X-4.0-Light-사용권-조사-20261017.md`, `docs/rag/m2/A.X-기준-계획-20261017.md`

## 맥락

- ADR-0031은 M2 검색 실험 모델을 Gemma 4 12B로 두고, 학습·운영 모델은 M2 끝(베이스라인 ②)에 Gemma 4 12B와 A.X 4.0 Light 중에서 고르기로 했다.
- 학습을 반드시 하기로 하면서(ADR-0033) 학습 계획을 한 모델에 맞춰 세울 필요가 생겼다.

## 결정

1. 학습하고 운영할 기반 모델은 A.X 4.0 Light(SKT, 7.26B, Apache 2.0)다(2026-10-17 사용자 결정). ADR-0031을 대체한다.
2. A.X의 약점(틀린 답, 답없는 질문의 거절)은 프롬프트 단계와 학습 1회차가 먼저 겨냥한다. M2 끝 성공 판정(ADR-0026)의 선은 그대로다.
3. 앞으로의 M2 실험에서 답을 만드는 모델은 A.X 4.0 Light다. 먼저 지금 운영 설정(순위 융합·근거 8개)으로 A.X 새 기준선을 잰다. Gemma 4 12B는 그 비교 기준으로만 남긴다.
4. 운영 기본 모델(`OLLAMA_LLM_MODEL`)은 A.X 새 기준선을 잰 뒤 바꾼다.

## 버린 대안

- Gemma 4 12B 유지: 틀린 답이 가장 적지만 생성이 약 2배 느리고, 학습 뒤 합칠 때 16비트 가중치(약 23.9GB)가 학습 서버 RAM 16GB를 넘는다.
- 베이스라인 ②까지 결정을 미룸: 학습 데이터·학습 설정을 한 모델에 맞춰 준비할 수 없다.

## 근거

| 항목 | A.X 4.0 Light | Gemma 4 12B | 근거 |
|---|---|---|---|
| 정답률(개발셋 본, 같은 순위 융합 프롬프트·근거 5개) | 71.1% | 74.4% | [실측] 같은 수준 p=0.48 |
| 틀린 답(본 149문항) | 10 | 1 | [실측] Gemma 나음 p=0.012 |
| 답없음 거절(본 28문항) | 82.1% | 100% | [실측] 목표 90%는 A.X만 미달 |
| 과잉 거절(본) | 11.6% | 19.0% | [실측] A.X 나음 p=0.012 |
| 생성 속도(데스크탑) | 86.3토큰/초 | 46.8토큰/초 | [실측] |
| 서빙 크기(4비트) | 약 4.5GB | 약 8.0GB | [실측] 데스크탑 Ollama |
| 원본 크기(16비트) | 약 14.5GB | 약 23.9GB | [원문·계산] 학습 서버 RAM 16GB |
| 라이선스 | Apache 2.0(바탕 Qwen2.5-7B도 Apache 2.0) | Apache 2.0 | [원문] 2026-10-17 |

- [계산] 서빙 크기가 작아 데스크탑 12GB에 생성 모델 + 임베딩(4.1GB) + 재순위 서버(약 1.3~2GB)가 함께 올라갈 여지가 생긴다 — Gemma로는 못 올렸다(3단계 보고서 §7). 실측으로 확인한다.

## 네 관점

- 서비스: 답이 약 2배 빨리 나오고 과잉 거절이 적다. 틀린 답은 학습·프롬프트로 줄여야 하며, 줄지 않으면 운영에 넣지 않는다(ADR-0033 결정 2).
- 비즈니스: 작은 모델이라 운영 GPU 비용이 낮다. 국산 기업(SKT) 모델이지만 바탕은 Alibaba Qwen2.5라 학교 제안서에서 설명한다.
- 유지보수: 7B라 학습·병합·변환이 학습 서버 한 대 안에서 끝난다(병합 메모리는 실측).
- 확장: 최대 문맥 16,384토큰 — 근거를 크게 늘리는 설계는 이 한도 안에서 한다.

## 결과

- 확신도: 중간 — A.X의 틀린 답이 프롬프트·학습으로 목표선 아래로 내려가는지는 아직 모른다.
- 검증 시점: A.X 새 기준선, 프롬프트 단계, 학습 1회차 전후 비교.
- 다시 검토할 조건: 프롬프트·학습 뒤에도 A.X가 오답률 5% 이하·답없음 거절 90% 이상을 넘지 못하면, Gemma 4 12B 학습을 다시 검토한다.
