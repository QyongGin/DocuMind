# ADR-0010: 학습 데이터 생성·리뷰와 AWS 반출 범위

- 상태: 채택
- 날짜: 2026-10-01
- 관련: `docs/project/설계6단계-결정근거대장-20261001.md` 안건 4
- 변경(2026-10-21): 리뷰 줄(무작위 200개 휴먼 리뷰, 오류 5% 이하 통과)은 ADR-0037로 바뀐다 — 자동 검사 → Claude 판정(통과·탈락만) → 사람은 첫 묶음에서 Claude 판정과 나란히 30개. 나머지 결정은 그대로다.
- 변경(2026-10-21): 초안 줄(AWS의 오픈 모델)은 ADR-0040으로 바뀐다 — 초안은 데스크탑의 Gemma 4 12B(Apache 2.0)로 만들고, 학습만 AWS에서 한다. Claude 출력을 학습에 쓰지 않는 것은 그대로다.
- 변경(2026-11-03): 반출 줄의 '서울 리전'을 바꾼다 — 학습 서버 리전은 학교가 준 인스턴스를 따르고, 1회차는 미국 동부(us-east-1)에서 학습한다. 개인정보가 든 자료와 국외 반출이 제한된 자료(AI 허브 데이터 등)는 서울 밖 리전에 올리지 않는다. 학습 몫만 올리고 끝나면 학교 데이터를 지우는 것은 그대로다. 이유: [실측] 학교가 준 학습 인스턴스(g5.xlarge)가 us-east-1에 있다. [실측] 1회차에 올리는 것은 학습 파일 200개(3.0MB)와 공개 모델뿐이다. 학습 파일은 학교 누리집 공개 글로 만든 예시로 개인정보 검사를 통과했고, 190개는 학교 사이트 문서에서 만들었으며 10개는 문서와 상관없는 범위 밖 거절이다. AI 허브 데이터는 없다. [판단] 서울을 고른 근거(데이터 최소화, AI 허브 데이터의 국외 반출은 별도 승인)가 이 파일에는 걸리지 않는다. 버린 안: 학교에 서울 인스턴스를 요청 — 받을 때까지 학습을 못 하고, 지금 올리는 자료에는 서울이어야 할 이유가 없다. 확신도: 높음. 검증 시점: 2회차 이후 학습 자료에 AI 허브 데이터나 개인정보가 든 문서를 넣을 때 다시 본다.

## 맥락

M2에서 학습 데이터를 만들 때, 서비스와 같은 입력 형식인지, 누가 만들고 어떻게 리뷰할지, AWS에 무엇을 올릴지 정해야 했다.

## 결정

- 학습 데이터는 서비스 파이프라인을 거친 결과로 만든다(같은 로더·청킹·프롬프트). 원본 레코드(질문·정답·근거 인용)와 파생(모델별 학습 파일)을 나누고, 데이터셋용 색인을 서비스 색인과 분리한다.
- 학습 데이터 초안은 AWS의 오픈 모델(Apache 2.0·MIT)로 만든다. EXAONE 출력은 쓰지 않고, Claude 출력은 학습에 쓰지 않는다. 행마다 만든 도구를 기록한다.
- 리뷰: 자동 검증 전부(인용 일치, 답 가능, 중복, 개인정보, 왕복 검사) + 무작위 200개 휴먼 리뷰, 오류 5% 이하만 통과.
- AWS에는 학습 몫만 올린다(청크 글, 학습 데이터, 공개 모델, 학습 결과물). 평가셋·개인정보 문서·원본 전체·내부 문서는 올리지 않는다. 서울 리전, 끝나면 학교 데이터 삭제.

## 근거

- [판단] 서비스에서 모델이 보는 입력은 원문이 아니라 출처 블록·답변 규칙이 붙은 프롬프트라, 원문으로 따로 만들면 다른 형식을 학습한다.
- [원문] EXAONE 라이선스는 출력으로 다른 모델 학습을 금지한다. Claude 약관은 경쟁 모델 학습 해석 문제가 있다.
- [원문] Self-Instruct 200개 표본 리뷰(전부 맞은 비율 54%), Promptagator 왕복 검사.
