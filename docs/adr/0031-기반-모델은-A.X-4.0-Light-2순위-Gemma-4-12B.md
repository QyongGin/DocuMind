# ADR-0031: 학습할 기반 생성 모델은 A.X 4.0 Light — 2순위 Gemma 4 12B, 학습 직전(베이스라인 ②)에 둘을 다시 비교한다

- 상태: 제안(2026-10-14, 사용자 확인 대기 — ADR-0027 순서를 그대로 적용한 결과)
- 날짜: 2026-10-14
- 관련: 이슈 #130, ADR-0004·0025·0027·0029·0030, `docs/rag/m1/모델비교-20261014.md`, `docs/rag/research/후보모델-공식챗봇-사용가능-심층조사-20261014.md`

## 맥락

- 지금 쓰는 EXAONE 3.5 7.8B는 연구용(NC) 라이선스라 학교 공식 서비스에 쓸 수 없다. 학습(LoRA)을 올릴 기반 모델을 먼저 정해야 M2 검색 설정(상위 k·문맥)과 M3 학습을 그 모델에 맞출 수 있다.
- 고르는 순서는 ADR-0027로 미리 정했다: ① 학습 서버(A10G 24GB) QLoRA 가능 ② 오답이 가장 적은 후보와 짝 비교해 오답이 의미 있게 많은 후보 빼기 ③ 정답률 1위 ④ 1위와 같은 수준이면 한국어 지문 읽기(KorQuAD 1.0, 우리 설정) 점수가 높은 후보 ⑤ 그래도 같으면 과잉 거절이 낮은 쪽.

## 결정

1. **1순위 A.X 4.0 Light**(SKT, 7.26B, Apache 2.0)를 M2·M3의 기준 생성 모델로 쓴다.
2. **2순위 Gemma 4 12B**(Google, 11.95B, Apache 2.0)는 같은 수준으로 남긴다. M2 검색 개선이 끝난 뒤 베이스라인 ②(학습 직전)에서 두 모델을 새 검색 프롬프트로 다시 짝 비교하고, 순서가 바뀌면 이 ADR을 대체한다.

## 버린 대안

- **Gemma 4 12B를 1순위로**: 본 합계 정답률(50.5% 대 48.5%)과 오답률(6.8% 대 10.0%), 근거가 있을 때 정답률(84% 대 76%)은 Gemma가 좋지만, 정답률·오답률 차이 모두 통계상 같은 수준(p=0.42, p=0.077)이다. 미리 정한 4단계(KorQuAD)에서 A.X 4.0 Light가 정확 일치로 의미 있게 높았다. 결과를 본 뒤 규칙을 바꾸면 고르는 기준이 흔들린다.
- **ADR-0027 순서 대신 여러 지표를 섞은 점수**: ADR-0023·0027에서 버렸다.

## 근거

- [실측] 13번(생성만 다시 돌리기, 베이스라인 프롬프트, 사고 끔·온도 0, 평가셋 v3, 본 250문항): A.X 4.0 Light 정답률 48.5%(97/200) · 오답률 10.0%(25/250) · 과잉 거절 31.5% · 본 테스트셋 정답률 48.1%(38/79, 후보 중 1위). Gemma 4 12B 50.5% · 6.8% · 35.0% · 45.6%.
- [실측] 2단계: 오답이 가장 적은 Gemma 4 12B(17건)보다 오답이 의미 있게 많아 빠짐 — Gemma 4 E4B(p=0.016), Qwen3-8B(p<0.001), Mi:dm 2.0 Base(p=0.0002), Tri-7B(p=0.0009).
- [실측] 3단계: 정답률 1위 Gemma 4 12B와 같은 수준 A.X 4.0 Light(p=0.42). 의미 있게 낮음 — A.X 3.1 Light(p=0.004), Qwen3-14B(p=0.013), Kanana 1.5 8B(p=0.027).
- [실측] 4단계: KorQuAD 1.0 개발 세트 500문항(시드 20261014, 측정 전에 정함), 같은 프롬프트·사고 끔·온도 0. A.X 4.0 Light EM 78.2 · F1 91.9, Gemma 4 12B EM 74.2 · F1 90.6. 짝 비교 EM 52 대 32(p=0.038), F1 차이 +1.3(95% 구간 −0.5~+3.0).
- [원문] 두 모델 모두 Apache 2.0(LICENSE 원문). A.X 4.0 Light는 Qwen2.5 기반이라는 모델 카드 문장("Built on the open-source Qwen2.5 model")이 있어 학교 제안 때 계보 설명이 필요하다.
- [계산] 학습 서버: 7B QLoRA 약 6GB로 A10G 24GB에 여유. 12B는 학습 뒤 병합 때 RAM 16GB가 빠듯하다(ADR-0030).
- [실측] 생성 속도(데스크탑 4070 Super): A.X 4.0 Light 85.6토큰/초, Gemma 4 12B 47.2토큰/초.

## 결과

- M2 검색 개선 실험(ADR-0032 제안)의 기준 모델을 A.X 4.0 Light로 바꾼다. 검색 효과는 같은 모델끼리 비교한다(A.X 4.0 Light의 13번 실행 → M2 실행).
- 확신도: 중간. 1·2순위 차이가 대부분 통계상 같은 수준이고, 4단계 KorQuAD 차이(EM +4.0)가 결정했다.
- 검증 시점: ① M2 실험 E3(새 검색 프롬프트로 두 모델 재생성) ② 베이스라인 ②(학습 직전) — 두 번 모두 Gemma 4 12B가 의미 있게 앞서면 이 결정을 다시 연다.
