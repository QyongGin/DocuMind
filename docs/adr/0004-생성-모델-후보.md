# ADR-0004: 생성 모델 후보와 판단 원칙

- 상태: 채택
- 날짜: 2026-10-01
- 관련: `docs/project/설계6단계-결정근거대장-20261001.md` 안건 1

## 맥락

지금 쓰는 EXAONE 3.5의 라이선스와 학교 공식 서비스 사용 가능성을 확인하고, 학습 전에 기반 모델을 골라야 했다.

## 결정

- EXAONE을 공식 챗봇 생성 모델 후보에서 뺀다. 베이스라인 비교용으로만 쓴다.
- 비교 후보: A.X 4.0 Light(SKT, Qwen2.5 기반), A.X 3.1 Light(SKT, 처음부터 학습, 품질 비교 전용·배포 후보 아님), Gemma 4 E4B(Google), Qwen3-8B(Alibaba).
- 판단 원칙(초안): 배포 조건(12GB에서 생성 문맥 8,192 + 임베딩 4B와 함께 올라감)을 통과한 후보 중 품질 1위. 국산 계보가 의미 없는 차이 안이면 국산 우선. 차이 기준은 M1 베이스라인 뒤 정한다.
- 비교는 M1 평가셋으로 하고(2단계 평가: 프롬프트 고정, 생성만 모델별, 잘리지 않는 큰 문맥), M2 학습 직전 상위 2개를 다시 비교한다.

## 버린 대안

- 처음 추천(A.X 4.0 Light + Qwen3-8B + Qwen3.5-9B): 세 모델 모두 Alibaba 계보이고 Qwen3.5-9B는 한국어 근거가 없었다.

## 근거

- [원문] EXAONE 3.5는 연구 목적 전용(NC), 4.x는 연구·교육 목적이라 공식 서비스 사용이 불가~불분명하다.
- [원문] 회사 표·수능 국어·호랑이 4의 순서가 서로 달라 일반 벤치마크로는 결론이 나지 않는다.
- [실측] A.X 3.1 Light는 KV 캐시가 토큰당 512KB로 임베딩과 함께 12GB에 못 올라간다(학습으로 못 고침).
