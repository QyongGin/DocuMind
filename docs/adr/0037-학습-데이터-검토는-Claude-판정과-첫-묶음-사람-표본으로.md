# ADR-0037: 학습 데이터 검토 — 자동 검사와 Claude 판정을 모두 거치고, 사람은 첫 묶음에서 Claude 판정과 나란히 30개를 본다

- 상태: 채택
- 날짜: 2026-10-21
- 관련: ADR-0010(리뷰 줄을 이 결정으로 바꿈), ADR-0019(평가셋 휴먼 리뷰 범위 — 같은 표본 문턱), ADR-0020(이중 라벨링), ADR-0033(학습 필수·운영 채택의 선), ADR-0035(단계 채택 규칙), `docs/rag/research/학습데이터-사람검토-실무조사-20261021.md`, `docs/rag/m2/A.X-기준-계획-20261017.md` §5·§6 일곱째

## 맥락

- [원문] ADR-0010(2026-10-01): 학습 데이터 리뷰는 자동 검증 전부 + 무작위 200개 휴먼 리뷰, 오류 5% 이하만 통과. 그때는 사람과 자동 검사 사이에 AI 판정 단계가 없었다.
- [계산] 학습 예시 하나는 질문 + 근거 8개(개발셋 프롬프트 중앙 3,422토큰) + 목표 답이라, 판정 이유·인용 줄 표시 없이 보면 1~2분이 든다. 200개는 3.3~6.7시간이고 데이터를 만들 때마다(학습 1~3회차) 되풀이된다.
- [판단] 자동 검사로 잡지 못하는 오류가 남는다: 근거에 있는 값이지만 다른 해·다른 행의 값, 근거에 답이 있는데 거절한 예시, 문서에 없는 문의처.
- 사용자 질문(2026-10-21): AI 판정에 맡기지 않고 사람이 붙어야 하는 이유는 무엇인가 → 실무 조사(관련 문서).

## 결정

1. 학습 데이터는 오픈 모델 초안 → 자동 검사 → Claude 판정 → 사람 표본 순서로 거른다(2026-10-21 사용자 결정).
   - 자동 검사: ADR-0010의 다섯 가지(인용 일치·답 가능·중복·개인정보·왕복 검사)에 더해, 정답이 근거 블록 글에 남았는지(발췌 규칙이 지운 예시 거르기)와 정답이 모호한 표 근거(같은 표 이름·행 이름·열에 값이 여럿)에만 기대는지(5단계 보고서 §8)를 본다.
   - Claude 판정: 예시마다 통과·탈락과 이유만 낸다. 글은 고치지 않는다. 탈락한 예시는 버리거나 오픈 모델로 다시 만든다 — ADR-0010의 'Claude 출력은 학습에 쓰지 않는다'는 그대로다.
2. 사람 표본은 첫 묶음에서 본다. 첫 묶음(약 40개)을 Claude가 판정하면 사람이 그중 30개를 Claude 판정과 나란히 본다. 답 · 거절 + 안내 · 표 질문을 고르게, Claude가 통과시킨 것과 탈락시킨 것을 모두 넣는다.
3. 사람과 Claude 판정이 2개 이상 어긋나면 판정 지침(필요하면 초안 지시문)을 고치고 새 30개를 본다. 1개 이하이면 나머지는 Claude 판정만으로 거른다.
4. 데이터를 만드는 방식(초안 모델·초안 지시문·판정 지침)이 바뀔 때만 새 30개를 본다. 같은 방식이면 학습 회차가 바뀌어도 다시 보지 않는다.
5. ADR-0010의 통과 기준 '무작위 200개에서 오류 5% 이하'는 이 결정의 2·3으로 바뀐다. 학습 데이터의 최종 품질은 학습 전후 개발셋 짝 비교(ADR-0033 결정 2, ADR-0035)로 본다.

## 버린 대안

- ADR-0010 그대로(사람 무작위 200개): 오류율은 좁게 잴 수 있지만(0개면 95% 상한 약 1.5%) 3.3~6.7시간이 데이터를 만들 때마다 든다. 판정 기준이 어긋난 것을 끝에서 알면 다시 만들어야 한다.
- 끝에서 통과분 30개(이 결정 직전의 추천): 사람 시간은 같지만, 기준이 어긋난 것을 2천여 개를 판정한 뒤에 알게 되고, Claude가 좋은 예시(특히 거절 예시)를 지나치게 버리는 쪽 오류가 보이지 않는다.
- Claude 판정만(사람 0분): Claude가 우리 과제에서 사람과 같은 판단을 하는지 모른 채 학습한다. 판정자를 사람 판단과 대조해 검증하라는 실무 권고(관련 조사 §3.2)에 어긋난다.
- 여러 모델 판정자(배심원 방식)·판정 확신도로 사람에게 보낼 예시 고르기: 판정 비용과 운영이 늘고, 판정자 검증은 그래도 사람 몫이다. 확신하며 틀린 예시는 걸러지지 않는다.

## 근거

- [원문] 실무에서 대량 생성·판정은 모델이 한다: Nemotron-4 340B 정렬 데이터 98% 이상 합성, Tülu 3 선호 라벨 LLM 판정, Anthropic 평가 문서 사람 채점 "Avoid if possible"(조사 §2).
- [원문] 판정 기준은 출력을 봐야 생긴다 — 기준 표류(Shankar 외 2024, 조사 §3.1). → 사람 표본을 처음에 둔다.
- [원문] LLM 판정자는 사람 판단과 대조해 검증한 뒤 써야 한다(Bavaresco 외 ACL 2025, 조사 §3.2). 작은 팀은 도메인 전문가 한 명이 맡는다(Husain·Shankar 2025).
- [원문] 답없음 예시는 사람 데이터가 앞섰다(ChatQA, 조사 §3.3). → 표본에 거절 예시를 반드시 넣는다.
- [원문] 모르던 사실을 담은 예시는 지어내는 경향을 늘린다(Gekhman 외 EMNLP 2024, 조사 §4). → 근거에 없는 값은 자동 검사로 먼저 거른다.
- [실측] 사람이 Claude 판정을 확인하는 데 10개 8분 35초(문항당 약 52초, `docs/rag/m1/베이스라인-측정-20261012.md`) → 30개 약 30분 [계산].
- [계산] 표본 30개에서 오류 0개면 오류율 95% 상한 약 10%. 표본의 목적은 오류율 보증이 아니라 판정 기준을 굳히고 판정자를 검증하는 것이다.

## 네 관점

- 서비스: 틀린 예시는 자동 검사와 Claude가 거르고, Claude가 우리 기준대로 판정하는지는 대량 판정 전에 사람이 확인한다. 학습한 모델은 전후 비교를 넘을 때만 운영에 들어간다(ADR-0033).
- 비즈니스: 사람 시간이 데이터마다 3.3~6.7시간에서 약 30분(어긋나면 1시간)으로 준다.
- 유지보수: 판정 지침이 문서로 남아 인계 뒤 재학습 때도 담당자 한 명이 30개만 보면 된다. 판정 지침은 특정 모델에 묶이지 않게 쓴다.
- 확장: 예시가 늘어도 사람 몫은 방식이 바뀔 때 30개로 같다. 판정 시간만 예시 수에 비례한다.

## 결과

- 확신도: 높음(사람 전수 검토를 하지 않는 방향), 중간(Claude가 한국어 학교 문서·표 판정에서 사람과 얼마나 맞는지 — 첫 묶음에서 처음 잰다).
- 검증 시점: M2 6단계 첫 묶음(사람·Claude 어긋남 수), 7단계 학습 1회차 전후 비교.
- 다시 검토할 조건: 첫 묶음에서 두 번 연달아 2개 이상 어긋나면 Claude 판정을 그대로 믿지 않고 판정 방식(판정 근거 범위, 판정 모델)을 다시 정한다. 학습 1회차에서 오답률이 의미 있게 늘면 데이터 오류부터 의심해 새 30개를 본다.
- ADR-0010에 이 ADR을 가리키는 변경 메모를 단다(리뷰 줄만 바뀜, 나머지 결정은 유효).
