# ADR-0031: 학습할 기반 생성 모델은 Gemma 4 12B — 2순위 A.X 4.0 Light, 학습 직전(베이스라인 ②)에 둘을 다시 비교한다

- 상태: 일부 확정(2026-10-15) — M2 검색 실험에서 답을 만드는 모델은 Gemma 4 12B. 학습·운영할 모델은 `docs/rag/m2/모델선정-비교계획-20261015.md`의 최종 비교(베이스라인 ②)에서 정한다(아래 '2026-10-15 변경')
- 날짜: 2026-10-14(변경 2026-10-15)
- 관련: 이슈 #130, ADR-0004·0025·0026·0027·0029·0030·0032, `docs/rag/m1/모델비교-20261014.md`, `docs/rag/m2/실패원인-분석-20261014.md` §6-1, `docs/rag/research/후보모델-공식챗봇-사용가능-심층조사-20261014.md`, `docs/rag/m2/모델선정-비교계획-20261015.md`

## 맥락

- 지금 쓰는 EXAONE 3.5 7.8B는 연구용(NC) 라이선스라 학교 공식 서비스에 쓸 수 없다. 학습(LoRA)을 올릴 기반 모델을 먼저 정해야 M2의 검색 설정(상위 k·문맥)과 그 뒤 학습(LoRA, 총괄계획 M2 'ML 적용')을 그 모델에 맞출 수 있다.
- 고르는 순서는 ADR-0027로 미리 정했다: ① 학습 서버(A10G 24GB) QLoRA 가능 ② 오답이 가장 적은 후보와 짝 비교해 오답이 의미 있게 많은 후보 빼기 ③ 정답률 1위 ④ 1위와 같은 수준이면 한국어 지문 읽기(KorQuAD 1.0, 우리 설정) 점수가 높은 후보 ⑤ 그래도 같으면 과잉 거절이 낮은 쪽.
- 같은 순서를 두 프롬프트에 적용했고 결과가 갈렸다.
  - 13번(지금 운영 검색, 규칙 경로의 프롬프트, 본 250문항): 1·2위 두 모델의 정답률·오답률이 같은 수준이라 4단계(KorQuAD)까지 가서 A.X 4.0 Light.
  - E3(M2에서 쓸 검색, 순위 융합 프롬프트, 개발셋 본 149문항): 2단계에서 A.X 4.0 Light가 빠져 Gemma 4 12B.
- 이 ADR은 2026-10-14 새벽에 13번 결과만으로 'A.X 4.0 Light 1순위'로 처음 썼고, 같은 날 E3 결과를 보고 사용자 확인 전에 고쳤다.

## 결정

1. **1순위 Gemma 4 12B**(Google, 11.95B, Apache 2.0)를 M2(검색 개선과 그 뒤 학습)의 기준 생성 모델로 쓴다.
2. **2순위 A.X 4.0 Light**(SKT, 7.26B, Apache 2.0)는 남긴다. M2 검색 개선이 끝난 뒤 베이스라인 ②(학습 직전)에서 두 모델을 그때 프롬프트로 다시 짝 비교하고, ADR-0027 순서의 결과가 바뀌면 이 ADR을 대체한다.
3. 모델을 고르는 비교는 **운영에 쓸 검색의 프롬프트**로 한다. 검색을 바꾸면 고른 모델을 다시 확인한다(ADR-0004의 '학습 직전 상위 2개 재비교'와 같은 원리).

## 버린 대안

- **13번 결과대로 A.X 4.0 Light를 1순위로**: 13번 프롬프트는 M2 1단계(ADR-0032)에서 버릴 규칙 경로의 프롬프트다. 앞으로 모델이 받을 프롬프트(순위 융합)에서 A.X 4.0 Light는 오답이 의미 있게 많아(10 대 1, p=0.012) ADR-0027 2단계를 통과하지 못한다. 오답률은 성공 기준 중 가장 엄한 지표다(ADR-0026, 목표 5% 이하 — A.X 4.0 Light 6.7%, Gemma 4 12B 0.7%).
- **'E3와 베이스라인 ② 두 번 모두 Gemma가 앞서면 다시 연다'(처음 쓴 조건)를 지키고 기다리기**: 처음 조건은 두 모델이 같은 수준일 때를 생각한 것이다. E3에서는 같은 수준이 아니라 거르기 단계에서 갈렸고, M2 실험 전체의 기준 모델이 이 결정에 달려 있어 베이스라인 ②까지 미루면 M2 실험을 다시 해야 한다. 아직 사용자 확인 전 제안이라 고쳐도 확정된 결정을 뒤집는 것이 아니다.
- **ADR-0027 순서 대신 여러 지표를 섞은 점수**: ADR-0023·0027에서 버렸다.

## 결과

- M2 검색 개선 실험(ADR-0032 제안)의 기준 생성 모델은 Gemma 4 12B다. 검색 효과는 같은 모델끼리 비교한다(Gemma 4 12B의 E3 실행이 M2 1단계 결과이자 다음 단계의 출발점).
- 운영 비용: 데스크탑 12GB에서는 생성이 A.X 4.0 Light보다 약 2배 느리다. M2 2단계(상위 k) 채택 기준의 응답 시간 상위 5%(6초)를 Gemma 4 12B로 다시 잰다. 학교 운영 서빙은 클라우드 예정(ADR-0030)이라 GPU를 그때 맞춘다.
- 학습(M2 'ML 적용'): 병합 단계 RAM은 학습 서버에서 실측하고, 모자라면 병합을 디스크 오프로드로 하거나, 병합하지 않고 어댑터를 붙여 서빙하는 방법을 확인한다. 이 확인은 학습 첫 작업에 넣는다.
- 확신도: 중간. E3는 개발셋(본 149)만이고 1·2위 두 모델만 다시 쟀다(A.X 3.1 Light·Qwen3-14B·Kanana 1.5 8B는 13번에서 정답률이 의미 있게 낮아 다시 재지 않음). 판정은 본 세션 한 명이 했다.
- 검증 시점: 베이스라인 ②(M2 검색 개선 뒤, 학습 직전) — 두 모델을 그때 프롬프트로 본 250문항 짝 비교. ADR-0027 순서 결과가 A.X 4.0 Light로 바뀌면 이 결정을 대체한다.

## 2026-10-15 변경: 학습할 모델은 두 모델 비교 계획으로 정한다

- 맥락: 사용자는 A.X 4.0 Light의 장점(생성 속도 약 두 배, 과잉 거절이 적음, 다음 할 일 안내·KorQuAD가 나음)을 보고, 틀린 답만 줄일 수 있다면 A.X도 1순위가 될 수 있다고 봤다. 두 모델을 자세히 비교한 뒤 최종 선정하기로 했다(사용자 결정, 2026-10-15).
- 결정:
  1. M2 검색 실험(상위 k·재순위·표 행 단위 색인)에서 답을 만드는 모델은 Gemma 4 12B로 고정한다. 검색만 바꾼 효과를 보기 위해서다.
  2. 학습·운영할 모델은 `docs/rag/m2/모델선정-비교계획-20261015.md`의 순서(① 근거 인용 후 답 ② 한 번 더 확인 — 두 모델에 같은 방법 → ③ 표 색인 뒤 A.X도 잼 → ④ 베이스라인 ②)로 비교하고, 실험 전에 고정한 규칙(ADR-0027 순서 + ADR-0026 선)으로 고른다.
  3. 속도·운영 비용은 순위에 넣지 않는다(운영 GPU는 ADR-0030에 따라 M6 전에 정함).
- 정정 [실측]: E3에서 A.X 4.0 Light가 틀린 10건은 실행 기록('정답 청크가 문맥에 있었나')·평가셋 '표 근거' 표시·판정 기록으로 나누면 **근거를 잘못 읽음 7건(표 5 · 글 2) + 근거가 없는데 답함 3건(정답 청크가 문맥에 없음 1 · 답없는 문항 2)**이다. 위 근거의 '9건 + 1건'은 정답 청크가 문맥에 없던 한 건(ev-0021)과 답없는 문항 한 건(ev-0116)을 '잘못 읽음'으로 센 것이다. 같은 10문항에서 Gemma 4 12B는 7건을 맞히고(답없는 2건은 맞게 거절) 3건을 거절했다.
- 추가 근거:
