# ADR-0009: ML 적용 계획: 구조 먼저, ML은 남은 실패에만

- 상태: 채택
- 날짜: 2026-10-01
- 관련: `docs/project/설계6단계-결정근거대장-20261001.md` 안건 3

## 맥락

ML·파인튜닝을 할지, 한다면 어디에 쓸지 정해야 했다.

## 결정

- ML은 필수가 아니다. 구조·설정 개선을 먼저 하고 ML은 남은 실패에만 쓴다.
- 주 대상: 생성 모델 행동 교정(LoRA, 프롬프트가 굳은 뒤). 보조: 임베딩 학습. 선택: 재순위(학습 없는 기성 모델부터). 라우팅 분류기는 하지 않고 메타데이터 필터로 대신한다.
- 채택 기준: 평가셋 전후 비교에서 의미 있는 차이 이상이고 다른 지표가 나빠지지 않을 것. 효과가 같으면 구조 개선을 고른다.
- M1 평가에 실패 유형 태그를 단다.

## 근거

- [실측] 6월 실제 문서 실패 26건 중 19건이 검색, 7건이 생성. 검색 실패는 청킹·범위 구조 문제, 생성 실패는 문맥 잘림이 유력(10월 실측으로 잘림 확인).
