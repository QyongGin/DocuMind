# ADR-0013: HWP·HTML·DOCX 형식 지원과 표 변환 규칙

- 상태: 채택
- 날짜: 2026-10-02
- 관련: 이슈 #125, PR #135, `docs/rag/m1/HWP-HTML-표변환-조사-20261002.md`

## 맥락

학교 문서의 상당수가 HWP·HTML이고, 마크다운 표는 셀 병합을 나타내지 못해 값이 빈칸이나 엉뚱한 열로 읽혔다.

## 결정

- HWP 5.0은 AI 서버에서 파이썬으로 직접 읽는다(olefile + 한컴 공개 문서). hwplib은 개발용 대조 기준으로만 쓴다. 표마다 격자 자기 검사, 해석 실패 시 글만 추출, 암호·배포용·HWP 3.0은 분명한 오류 문구.
- 표 변환 규칙(HWP·HWPX·HTML 공통): 1×1 표는 글로, 맨 윗줄이 전체 폭 한 칸이면 표 위 제목 글줄로, 왼쪽 위 칸이 k줄 세로 병합이면 머리 k줄을 한 줄로 합침, 세로 병합 값은 줄마다 채움, 본문 가로 병합은 열 이름이 서로 다르고 20자 이하일 때만 채움, 표 안의 표는 칸 안 글로.
- DOCX도 mammoth HTML을 거쳐 같은 표 격자로 바꾼다. XLSX·PPTX는 그대로.
- 이어진 두 표 사이에 `<!-- -->` 줄을 넣는다. 기존 표 블록 나누기 함수는 PDF 영향 때문에 고치지 않는다.

## 버린 대안

- hwplib을 서비스에 넣기: 코드가 자바·파이썬 두 언어로 나뉘어 인계 부담이 커진다.
- 첫 줄 = 열 이름, 가로 병합은 첫 칸만: [실측] HWP 표 250개에서 1,900칸이 빈칸으로 읽혔다.

## 근거

- [실측] hwplib과 표 구조 2,276/2,276 동일, 글자 누락 0, HTML 칸 밀림 385 → 0.
