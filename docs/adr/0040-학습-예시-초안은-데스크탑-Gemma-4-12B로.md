# ADR-0040: 학습 예시 초안은 데스크탑에서 Gemma 4 12B로, 사용자·질문 유형별 비율을 정해 만든다

- 상태: 채택
- 날짜: 2026-10-21
- 관련: ADR-0010(초안 줄을 이 결정으로 바꿈), ADR-0037(검토 — Claude 판정), ADR-0039(목표 답 모양), ADR-0008(학습·평가 분리), ADR-0031(Gemma 4 사용권 원문 확인), `docs/rag/research/학습셋-제작-실무조사-20261021.md`, `docs/rag/m1/모델비교-20261014.md`, `docs/rag/m2/2단계-A.X-새기준선-20261020.md`

## 맥락

- ADR-0010은 학습 데이터 초안을 "AWS의 오픈 모델(Apache 2.0·MIT)"로 만들고 Claude 출력은 학습에 쓰지 않기로 했다. 학교 AWS 학습 서버의 접속 정보는 아직 없다.
- 초안 모델은 학습 예시의 질문과 목표 답을 쓴다. 목표 답은 근거 8개를 읽고 답하는 일이라, 우리 평가셋에서 같은 일을 잘한 모델이 맞다.
- [실측] 같은 프롬프트에 생성 모델만 바꾼 비교에서 Gemma 4 12B가 틀린 답이 가장 적었다: 13번 모델 비교(본 250) 오답률 6.8%(A.X 4.0 Light 10.0%, Qwen3-14B 9.6%), 정답률 1위. 지금 운영 설정(개발셋)에서 오답률 1.3% 대 A.X 6.0%(p=0.039). 약점은 안내가 짧다는 것이다(쉬운 문항 안내 충실도 28.9% 대 A.X 52.6%).
- 2026-10-21 사용자가 Claude로 초안을 만들 수 없는지 물었다.

## 결정

1. 학습 예시(질문·목표 답) 초안은 **데스크탑의 Gemma 4 12B**(`gemma4:12b-it-qat`, 데스크탑 모델 볼륨에 등록돼 있음)로 만든다(2026-10-21 사용자 결정). 학습(LoRA)은 그대로 AWS에서 하고, AWS에는 학습 몫 데이터만 올린다(ADR-0010).
2. Claude는 판정(통과·탈락)에만 쓰고 초안을 쓰지 않는다(ADR-0010·0037 그대로).
3. 질문을 만들기 전에 사용자 범주(재학생 · 예비 입학생·지원자 · 교직원 · 외국인 · 업체)와 질문 유형(사실 하나 · 절차·방법 · 표 값 · 여러 근거 합치기 · 답없음)별 개수를 정하고 범주별로 만든다. 사용자 범주는 간단히 주고 길이·말투를 바꿔 지시하며, 다 만든 뒤 범주별 개수와 비슷한 질문 중복을 확인한다.
4. 초안 도구는 모델 이름을 설정으로 받는다. 본 학습(2회차) 전에 AWS가 있고 1회차에서 Claude 탈락률이 높으면 더 큰 오픈 모델(예: Gemma 4 31B)을 그때 다시 본다.

## 버린 대안

- Claude로 초안: 품질은 가장 좋을 수 있다. 하지만 ① 소비자 약관 3조("인공 지능 또는 기계 학습 알고리즘 또는 모델을 개발 또는 훈련하는 것을 포함하여 당사 서비스와 경쟁하는 상품 또는 서비스 개발" 금지)·상업 약관 D.4("to build a competing product or service, including to train competing AI models")의 해석 위험을, 학습한 모델을 넘겨받는 학교가 진다. ② 판정(Claude)과 평가셋 초안(Claude)이 같은 계열이라, 그 데이터로 학습한 모델을 판정이 편든다(Preference Leakage, ICLR 2026).
- AWS를 기다려 더 큰 오픈 모델: 우리 과제로 잰 적이 없고 시작 시점을 알 수 없다.
- A.X 4.0 Light 자신: 빠르고 안내가 길지만 틀린 답이 더 많아, 학습이 고치려는 약점을 다시 배운다.
- Qwen3-14B(Alibaba, Apache 2.0): 13번에서 정답률이 Gemma보다 의미 있게 낮았고(p=0.013) 12GB GPU에 다 올라가지 않았다.
- 문서마다 한 번의 프롬프트로 질문 뽑기: 흔한 생성 도구는 치우치고 다양하지 않은 질문을 만든다(DataMorgana, Know Your RAG).

- [실측] 위 오답률·정답률(`docs/rag/m1/모델비교-20261014.md` §3·§4, `docs/rag/m2/2단계-A.X-새기준선-20261020.md` 결론 2).
- [원문] Gemma 4는 Apache 2.0(ADR-0031, 2026-10-15 원문 재확인). Anthropic 약관 문장(2026-10-21 원문 확인: 소비자 약관 2025-10-08 시행, 상업 약관 2025-06-17 시행).
- [원문] Preference Leakage(Li 외, ICLR 2026), DataMorgana(Filice 외, 2025), Know Your RAG(Teixeira de Lima 외, COLING 2025), 페르소나 프롬프트의 다양성(Kambhatla 외, EMNLP 2025 Findings) — `docs/rag/research/학습셋-제작-실무조사-20261021.md`.
- [판단] 초안을 데스크탑에서 만들면 학교 문서가 학습 전까지 데스크탑 밖으로 나가지 않는다. ADR-0010의 흐름(데스크탑 청크 → AWS 초안 → 데스크탑 검사 → AWS 학습)에서 초안 왕복이 빠진다.

## 네 관점

- 서비스: 같은 근거에서 틀린 답이 가장 적은 모델의 답을 학습해 A.X의 약점(근거가 있어도 틀린 답)을 겨냥한다.
- 비즈니스: AWS를 기다리지 않고 6단계를 지금 진행한다. 비용은 데스크탑 시간(생성 약 47토큰/초)이다.
- 유지보수: 평가에 쓰던 모델·Ollama 그대로라 새로 설치할 것이 없다. 예시마다 만든 모델 이름을 기록한다(ADR-0010).
- 확장: 모델 이름을 설정으로 받아, 큰 모델로 바꿀 때 코드를 고치지 않는다.

## 결과

- 확신도: 중간 — 질문 만들기 품질은 아직 재지 않았다. 첫 묶음의 Claude 탈락률과 사람·Claude 어긋남(ADR-0037)에서 처음 본다.
- 검증 시점: 6단계 첫 묶음, 7단계 1회차 전후 비교.
- 다시 검토할 조건: 첫 묶음 탈락률이 높거나 질문이 한쪽 유형으로 몰리면 지시문을 고치고, 그래도 안 되면 초안 모델을 바꾼다.
- ADR-0010에 변경 메모를 단다(초안 장소·모델만 바뀜).
