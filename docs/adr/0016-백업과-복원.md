# ADR-0016: DB·색인 백업과 복원

- 상태: 채택
- 날짜: 2026-09-30
- 관련: `docs/deployment/DB-색인-백업-복원-절차.md`

## 맥락

색인이 컨테이너 안에만 있어 지워질 위험이 있었고, 백업이 실제로 복원되는지 확인한 적이 없었다.

## 결정

- 백업·복원은 수동 스크립트(`deploy/backup.sh`·`restore.sh`)로 하고 데스크탑 `~/backups/documind/`에 둔다.
- 복원 리허설은 운영과 분리된 임시 compose 프로젝트에서 하고, 건수만이 아니라 MySQL 재덤프·Chroma id·본문·메타데이터·임베딩 해시까지 비교한다.
- 정기 실행·보관 기간은 학교 서버(M4)에서 정한다.

## 근거

- [판단] 데스크탑은 작업할 때만 켜므로 예약 실행이 맞지 않는다.
- [실측] compose MySQL 헬스체크(`mysqladmin ping`)는 초기화 도중에도 healthy가 되어, 스크립트는 TCP 로그인으로 준비를 확인한다.
