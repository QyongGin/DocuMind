# ADR-0003: 실행 환경: 데스크탑 서빙, AWS 학습, 필요할 때만 켜기

- 상태: 채택
- 날짜: 2026-09-30 (2026-10-01 보완)
- 관련: 루트 AGENTS.md §3

## 맥락

GCP 무료 크레딧 시기 이후, 챗봇을 어디서 돌리고 모델을 어디서 학습할지 정해야 했다.

## 결정

- 챗봇 실행(서빙)·평가·색인은 데스크탑(RTX 4070 Super 12GB, WSL2 + Docker, `docker-compose.gpu.yml` 필수)에서 한다. GCP는 쓰지 않는다.
- 모델 학습(파인튜닝)만 AWS EC2 g5.xlarge(A10G 24GB, 서울)에서 한다.
- 데스크탑은 상시 가동하지 않고 작업할 때만 켠다. 자동 로그인·절전 끄기는 하지 않는다. 상시 가동은 학교 서버 운영(M6)의 요건으로 둔다.

## 버린 대안

- 클라우드 GPU 임대 상시 서빙: 비용.
- 데스크탑에서 학습: 12GB로는 7~8B 모델 학습이 어렵다.

## 근거

- [판단] 사용자 결정(전기 요금 부담, 학습 서버는 사용자가 마련).
