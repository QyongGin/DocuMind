# ADR-0015: 표 사실 조회를 메모리 캐시로

- 상태: 채택
- 날짜: 2026-10-04
- 관련: 이슈 #139, PR #140, `docs/rag/m1/서비스-전체-색인-및-측정-20261004.md`

## 맥락

서비스 전체 색인(표 사실 45,878개)에서 표 사실 전체 조회가 `too many SQL variables`로 실패해, 표 근거가 소리 없이 빠지고 Chroma 메모리가 9.25GB까지 올랐다.

## 결정

- 표 사실을 나눠 가져와 처음 한 번 메모리에 두고(업로드·삭제 때 BM25와 함께 무효화), 질문마다 메모리에서 채점한다. 채점 규칙은 그대로다.

## 버린 대안

- 나눠 가져오기만: 질문마다 4.6만 개 전송·채점(맥북 실측 2.17초)이 남는다.
- 표 사실 상한: 평가 없이 정하면 표 답을 잃을 수 있다(M2에서 평가와 함께 검토).

## 근거

- [실측] 표 질문 0.65~1.25초, Chroma 1.35GB, 첫 표 질문만 캐시 만들기 15.6초.
