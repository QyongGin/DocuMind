# ADR-0021: 에이전트 문서 공개와 문서 구조

- 상태: 채택
- 날짜: 2026-10-07
- 관련: 루트 AGENTS.md §6, `docs/workflow/클라우드-세션-작업-절차.md`

## 맥락

클라우드 세션(claude.ai/code 등)은 GitHub 저장소 클론만 보고, 사용자 메모리와 gitignore 파일은 넘어가지 않는다. 에이전트 문서(AGENTS.md, CLAUDE.md, memory-bank, docs)는 "노하우 비공개" 방침으로 모두 gitignore돼 있었다. 또 memory-bank는 AI 코딩 도구 커뮤니티 관례(Cline Memory Bank)라 실무 형식과 달랐고, 결정 기록과 작업 이력이 두 곳에 중복돼 있었다.

## 결정

- 에이전트 문서의 현재본을 공개 저장소에 커밋한다. 지난 기록은 `docs/archive/`, 접속 정보·개인 문서는 `docs/local/`, 학교 데이터는 `Assets/`에 두고 커밋하지 않는다.
- memory-bank를 실무 구조로 바꾼다.
  - 현재 위치와 다음 할 일 → `docs/project/현재-상태.md`(인수인계 노트)
  - 작업 큐 → GitHub Issues·마일스톤 + Projects 보드
  - 결정 기록 → `docs/adr/`(이 폴더, 결정 하나 = 파일 하나)
  - 작업 이력 → PR 본문과 작업 보고서
  - 문서 운영 규칙 → `docs/workflow/AGENTS-및-AI문서-운영기준.md` 한 곳
- 사용자와 합의한 작업 방식은 루트 `AGENTS.md` §4에 둔다(로컬·클라우드 공통).

## 버린 대안

- 비공개 문서 저장소를 따로 두고 세션에 두 저장소 연결: 관리가 번거롭다(사용자).
- 저장소 비공개 전환: 포트폴리오 공개가 안 된다.

## 근거
