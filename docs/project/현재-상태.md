## 배운 것·도구 빈틈

- 데스크탑 평가: 맥북 Unicorn VPN 끄기. WSL `ssh desktop`이 자주 시간 초과 → `ssh desktop-win "wsl -d Ubuntu -- bash -s"`에 명령을 표준 입력으로. AI 서버 터널도 `desktop-win`. 원격 빌드는 `DOCKER_CONFIG=~/.docker-nocreds`
- 데스크탑 `.env`에 값이 직접 적혀 있으면 compose 기본값 변경이 먹지 않는다 — 기본값을 바꾸는 PR은 데스크탑 `.env`부터 확인
- 같은 설정 재실행의 흔들림 두 가지(2026-10-16 실측, `docs/development/알려진-문제.md`): 같은 질문의 첫 임베딩만 미세하게 다름(디버그 추적과 `/query` 비교 전에 한 번 먼저 부른다), 근거 꼬리표가 서버를 띄울 때마다 바뀜(`_extract_item_label`, 수정은 별도 작업으로 제안함)
- 서브에이전트 판정·조사·문서는 빠르지만 근거 없는 숫자·겹친 그림이 섞였다. 결정에 쓰는 숫자·인용은 본 세션이 원문으로 다시 확인하고, 그림은 캡처를 직접 연다
- 실행 기록에 검색기별 점수와 레이아웃 표 사실의 부모 청크 id가 없어 오프라인 비교에 한계 — M2 3단계에서 평가 기록에 더함
- 커뮤니티 GGUF는 채팅 틀이 Jinja 그대로라 Ollama 틀을 직접 지정해야 함(`Assets/eval/work/13/*_create.json`)
