## 배운 것·도구 빈틈

- 데스크탑 평가: 맥북 Unicorn VPN 끄기. WSL `ssh desktop`이 자주 시간 초과 → `ssh desktop-win "wsl -d Ubuntu -- bash -s"`에 명령을 표준 입력으로. AI 서버 터널도 `desktop-win`. 원격 빌드는 `DOCKER_CONFIG=~/.docker-nocreds`
- 데스크탑 `.env`에 값이 직접 적혀 있으면 compose 기본값 변경이 먹지 않는다 — 기본값을 바꾸는 PR은 데스크탑 `.env`부터 확인

- 실행 기록에 검색기별 점수와 레이아웃 표 사실의 부모 청크 id가 없어 오프라인 비교에 한계 — M2 3단계에서 평가 기록에 더함
