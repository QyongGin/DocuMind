## 배운 것·도구 빈틈

- 데스크탑 평가: 맥북 Unicorn VPN 끄기. WSL `ssh desktop`이 자주 시간 초과 → `ssh desktop-win "wsl -d Ubuntu -- bash -s"`에 명령을 표준 입력으로. AI 서버 터널도 `desktop-win`. 원격 빌드는 `DOCKER_CONFIG=~/.docker-nocreds`
- 맥북에 Ollama가 떠 있으면 ai-server 테스트가 진짜 Ollama를 부르고도 통과한다(#180 CI에서 드러남) — `OLLAMA_BASE_URL=http://127.0.0.1:9`로 돌린다
- 데스크탑 `.env`에 값이 직접 적혀 있으면 compose 기본값 변경이 먹지 않는다 — 기본값을 바꾸는 PR은 데스크탑 `.env`부터 확인
- 같은 설정 재실행 흔들림 두 가지 모두 고침: 근거 꼬리표 순서(#178), 질문 임베딩(1단계 — Ollama 입력 캐시). Ollama 판을 올리면 임베딩 측정(`임베딩-흔들림-수정-20261020.md` §2)을 다시 한다
- 긴 세션은 요약되며 학습 목표 같은 상위 맥락이 빠진다 — 계획을 바꾸기 전에 ADR-0033·0010·총괄계획 M2를 다시 읽는다
- 서브에이전트 판정·조사·문서는 빠르지만 근거 없는 숫자·겹친 그림이 섞였다. 결정에 쓰는 숫자·인용은 본 세션이 원문으로 다시 확인하고, 그림은 캡처를 직접 연다
- 커뮤니티 GGUF는 채팅 틀이 Jinja 그대로라 Ollama 틀을 직접 지정해야 함(`Assets/eval/work/13/*_create.json`) — 학습한 A.X를 올릴 때도 같다
