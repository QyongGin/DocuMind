## 배운 것·도구 빈틈

- 데스크탑 평가: 맥북 Unicorn VPN 끄기. WSL `ssh desktop`이 자주 시간 초과 → `ssh desktop-win "wsl -d Ubuntu -- bash -s"`에 명령을 표준 입력으로 보내면 됨. Ollama·AI 서버 터널도 `desktop-win`
- 긴 실행은 nohup + 로그. 같은 GPU를 쓰는 실험은 이어 붙이는 대기열 스크립트로(`Assets/eval/work/m2/gpu_queue.sh`)
- 맥북 MPS(PyTorch)는 백그라운드 프로세스에서 멈춤 → 전면 실행으로 나눠 돌리고 이어 하기(`rerank_offline.py`의 partial 파일)
- 서브에이전트 판정·조사는 빠르지만 근거 없는 인용·체계적 편향이 섞였다(존재하지 않는 모델 크기, 출처 회사 혼동). 결정에 쓰는 숫자·인용은 본 세션이 원문으로 다시 확인
- 커뮤니티 GGUF는 채팅 틀이 Jinja 그대로라 Ollama 틀을 직접 지정해야 함(`Assets/eval/work/13/*_create.json`)
