## 배운 것·도구 빈틈

- 답없음 부재 확인 순서: ① 핵심 개념 낱말 하나 → ② 같은 것을 부르는 다른 이름 → ③ 걸린 글 읽기(리뷰 지침 §4). 답없음 정답 글은 '문서에서 확인할 수 없다'로 시작하고 문서의 확인처·문의처로 끝낸다(잘못된 전제 문항도 같음 — 26번 고침). 쉬운 문항 '어디에 문의해요?'는 답 부서가 질문 낱말과 같으면 채점이 저절로 맞음이 되니 피한다
- 2027 모집요강 색인 글에 빈 문자(NUL) 5,429개 — 일반 grep이 건너뜀. 찾기는 Python으로(12번 단계 기록에서 청크에도 있는지 확인, M2 청크 정리)
- 테스트셋 노출(2026-10-12 결정, ADR-0018 보완): 판정 때 테스트셋 27문항의 실행 기록을 봤지만 규칙대로 옮기면 정답률이 35.0% → 43.3%로 쏠려 ev-0002만 옮긴다. 테스트셋 판정 자료에는 질문·정답·챗봇 답·허용 근거 원문만
