# 학교 문서 오류 목록

> 학교 홈페이지·게시판 글에서 찾은 오기와 서로 맞지 않는 내용을 모은다. 인계(M4 인계 패키지, M6 운영) 때 학교 담당 부서에 알릴 목록이다. 챗봇은 문서에 적힌 대로 답하므로, 학교가 글을 고치면 답도 바로 정확해진다.
> 새로 찾으면 이 표에 행을 더하고, 작업 보고서에는 이 파일 링크만 둔다(2026-10-12 사용자 결정). 공개 저장소라 원문은 짧게만 옮긴다.
