# 챗봇 답변 형식

> 사용자 화면에 보이는 답의 모양과, 그 모양을 만들기 위해 모델·서버·학습 데이터가 지키는 약속이다. 2026-11-01 확정, 2026-11-02 거절 문장 변경(ADR-0050). 답 모양을 바꾸려면 이 문서와 ADR을 함께 고친다.
> 예시는 지어낸 학교(가나대학)다.

## 1. 사용자 화면

답은 세 부분이고, 말투는 합니다체다.

| 순서 | 부분 | 내용 | 만드는 곳 |
|---|---|---|---|
| 1 | 결론 | 질문에 대한 답을 첫 문장에 | 모델 |
| 2 | 안내 | 근거에 있는 다음 할 일: 방법, 기한, 문의처, 사이트 | 모델 |
| 3 | 참고한 문서 | 사이트 › 게시판, 게시글 제목(원문 보기), 첨부 파일 이름, 게시일 | 서버(문서 대장) |

사용자 화면에 보이지 않는 것: 출처 번호, 청크 본문, 검색 후보 목록, 업로드 시각, 검색 점수. 이것들은 개발자 모드(§4)에서만 본다.

## 2. 경우별 모양

### 답이 있을 때

모델 출력:

```text
2026학년도 2학기 휴학 신청 기간은 2026. 8. 18.(화) ~ 8. 29.(토)입니다. 종합정보시스템의 휴학 신청 메뉴에서 신청하고, 문의는 학사지원팀(02-000-0000)으로 하시면 됩니다.

[출처 1]
```

사용자 화면:

```text
2026학년도 2학기 휴학 신청 기간은 2026. 8. 18.(화) ~ 8. 29.(토)입니다. 종합정보시스템의 휴학 신청 메뉴에서 신청하고, 문의는 학사지원팀(02-000-0000)으로 하시면 됩니다.

참고한 문서
가나대학 홈페이지 › 학사 공지
2026학년도 2학기 휴학 신청 안내  [원문 보기]
게시 2026-08-10
```

### 일부만 없을 때

모델이 '(없는 것)은 학교 홈페이지 안내에서 찾지 못했습니다'라고 쓰고, 화면에도 그대로 보인다.

```text
통학버스는 기존보다 20분 앞당겨 운행됩니다. 버스 요금은 학교 홈페이지 안내에서 찾지 못했습니다.

참고한 문서
가나대학 홈페이지 › 학사 공지
통학버스 일부 노선 출발시간 조정 운행 안내  [원문 보기]
```

### 답이 없고, 근거에 문의처가 있을 때

```text
학교 홈페이지 안내에서 이 내용을 찾지 못했습니다. 장학팀(02-000-0001)으로 문의하시기 바랍니다.

참고한 문서
가나대학 홈페이지 › 장학 공지
2026학년도 1학기 가나장학금 신청 안내  [원문 보기]
```

참고한 문서는 문의처가 나온 문서다.

### 답이 없고, 문의처도 없을 때

모델 출력은 거절 문장 하나다(`학교 홈페이지 안내에서 이 내용을 찾지 못했습니다.`). 화면에는 서버가 정해 둔 안내를 붙인다.

```text
학교 홈페이지 안내에서 이 내용을 찾지 못했습니다.

이렇게 확인해 보세요
· 학과, 학년도, 학기를 넣어 다시 질문하기
· 담당 부서에 전화 문의: 교내 전화번호 안내  [바로가기]
```

'없습니다'로 단정하지 않는다. 못 찾은 것과 없는 것을 가를 수 없다.

### 링크가 열리지 않을 때

서버가 답 속 링크를 확인해, 열리지 않으면 링크 자리에 '신청 링크(지금 열리지 않음)'처럼 보인다. 신청 양식 주소면 '신청 링크', 그 밖은 '링크'라고 쓴다.

## 3. 모델 출력 → 화면(서버가 하는 일)

| 모델 출력 | 화면 |
|---|---|
| 끝의 `[출처 N]` | 지우고, N번 근거의 문서 대장 정보로 '참고한 문서'를 만든다. 같은 문서는 한 번만 |
| 거절 문장만 있음(`학교 홈페이지 안내에서 이 내용을 찾지 못했습니다.`) | 정해 둔 안내를 붙이고, 참고한 문서는 보이지 않는다. 못 답한 질문 목록에 남긴다 |
| `<https://…>` | 꺾쇠를 떼고 링크로 보인다 |
| 열리지 않는 링크 | '(신청) 링크(지금 열리지 않음)'으로 바꾼다 |

참고한 문서 만드는 법:

- 사이트 이름: 대표 홈페이지는 '학교 홈페이지', 입학 사이트는 '입학 홈페이지', 학과 사이트는 학과 이름 + '홈페이지'.
- 게시판 이름: 대장의 게시판 이름에서 번호를 빼고 '공지'를 붙인다(예: '학사(11)' → '학사 공지'). 학사규정은 '학사규정'.
- 첨부 파일은 게시글로 연결하고 파일 이름을 따로 보인다. 게시글이 대장에 없으면 첨부 파일 자체로 연결한다.
- 근거 블록의 '문서:' 줄(파일 이름)은 쓰지 않는다. 따옴표와 빗금이 깨져 있다.
- 유효 기간이 지난 공지에 '지난 안내'를 다는 일은 문서 대장의 유효 기간을 바로잡은 뒤에 한다. 지금은 게시일만 보인다.

## 4. 개발자 모드

관리자로 로그인했을 때만 답마다 아래를 보인다.

- 모델 원문 답(출처 번호 포함)
- 근거 8개: 문서, 청크 본문, 검색 점수(답이 쓴 근거 표시)
- 프롬프트, 단계별 걸린 시간
- 화면 처리 내역: 지운 출처 번호, 붙인 안내, 숨긴 링크
- 못 답한 질문 목록(거절 문장만 나간 질문)

## 5. 지키는 것

- 근거에 없는 내용, 일반 조언, 지어낸 값을 쓰지 않는다(운영 규칙 1·2·9·10·11).
- 문서 이름과 주소는 모델이 쓰지 않는다. 서버가 문서 대장에서 가져온다.
- 모델 출력의 약속(끝의 `[출처 N]`, 거절 문장)은 운영 프롬프트 규칙 9·11(ai-server `MANDATORY_RAG_PROMPT`)과 학습 데이터가 함께 지킨다. 거절 문장은 서버가 바꾸지 않고 화면에 그대로 보인다.
- 거절 문장을 바꾸려면 운영 프롬프트, 학습 데이터 도구(`tools/corpus` trainset `prompts.REFUSAL_RULES`), 채점의 거절 낱말 목록을 함께 고치고 다시 학습한다. 급하면 서버가 화면에서 덮어쓸 수 있다.

## 6. 학습 데이터와의 관계

- 학습 목표 답은 §2의 '모델 출력' 모양이다(ADR-0039 결정 1). 화면 모양은 서버가 만들므로 학습 데이터를 다시 만들지 않는다.
- 학습 파일로 내보낼 때 세 가지만 다르다: 거절 문장 뒤에 출처 번호만 있으면 지운다(ADR-0050 결정 4). 인용형 모양은 만들지 않는다(결정 7). 2026-11-02 전에 만든 묶음의 옛 거절 문장(`제공된 문서에서는 확인할 수 없습니다.`)은 목표 답과 입력의 운영 규칙 9·11에서 함께 새 문장으로 바꾼다(ADR-0050 2026-11-02 변경).
- 학습한 모델은 거의 모든 답에 출처 번호를 단다. 그래서 학습한 모델을 운영에 올리기 전에 §3의 서버 처리와 §4의 개발자 모드를 끝낸다(결정 8).
