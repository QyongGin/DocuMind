# 설계 6단계(ML 설계) 결정 근거 대장 (2026-10-01)

> 목적: 결정마다 **무엇을 정했고, 무엇과 비교해 버렸고, 근거가 무엇이며(종류·출처), 얼마나 확실하고, 아직 무엇을 모르는지**를 한곳에 남긴다. 면접·학교 제안·인계·후일 재검토 때 이 문서로 설명한다.
> 결정 본문은 총괄계획 §4.6·§7, 상세 근거는 각 행의 보고서에 있다. 이 문서는 근거의 **종류와 강도**를 정리한 색인이다.
> 작성 계기: 사용자 요청 — "각 라인의 이유를 대고 근거가 있었다, 다른 방도보다 나은 방법이었다 자신할 수 있나. 문서에는 근거를 남겨야 한다. 후일에 대비해서."

## 0. 읽는 법

| 근거 종류 | 뜻 | 면접에서 말하는 법 |
|---|---|---|
| **[실측]** | 우리가 직접 잰 값(데스크탑·맥북·학교 누리집) | "직접 재 보니 ○○였다" |
| **[원문]** | 법령·라이선스·공식 문서·논문을 원문 글자로 확인 | "○○ 원문에 ○○라고 되어 있다" |
| **[계산]** | 실측·원문 값으로 계산한 추정(가정을 밝힘) | "○○를 가정하고 계산하면 ○○다. ○○ 때 실측으로 확인한다" |
| **[판단]** | 근거를 바탕으로 한 선택. 다른 답도 가능 | "근거는 ○○이고 그래서 ○○를 골랐다. 틀렸는지는 ○○로 확인한다" |

- 확신도: **높음**(실측·원문이 직접 받침) · **중간**(근거는 있으나 판단·가정이 섞임) · **낮음**(추정 위주, 실측 전).
- 판단이 섞인 결정도 "근거 + 가정 + 검증 시점"을 함께 적어 두면 방어할 수 있다. 판단을 사실처럼 말하지 않는다.
