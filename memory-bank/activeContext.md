## 반드시 알아야 할 사실

- **평가셋 94런 중 44런은 Claude가 만든 합성 문서(DOCX·PPTX·XLSX) 기준**이다. 인하공전 사실 정확도 지표로 쓰지 않는다. 실제 문서 평가셋은 M1에서 새로 만든다.
- **데스크탑은 작업할 때만 켠다**(전기 요금). `ssh desktop`이 안 되면 맥북 Tailscale → 데스크탑 전원 → WSL 순으로 의심. 절차: `docs/development/local-gpu/데스크탑-작업-시작-종료-절차.md`.
- Chroma 색인은 이제 볼륨에 저장된다(#115). 백업: `deploy/backup.sh documind_desktop` → 데스크탑 `~/backups/documind/<시각>/`(최신 `20261003-215739`, A5 정리 직전). M0-1의 `~/backups/chroma/20260930-181322/`도 남아 있다. `docker compose down -v`는 여전히 금지.
- **A5 정리 완료(2026-10-03 결정 A)**: 색인 101~105 삭제, DB 3·4번 삭제(사용자) → DB 활성 41개 = 색인 document_id 41개. 이후 서비스 색인은 `corpus upload`(대장 경로)로만. 옛 색인은 백업 `20260930-*`·`20261003-200622`에 있음.
- **묶음 임베딩은 같은 조건에서도 결과가 조금씩 다르다**(16개 묶음 두 번에 9/16만 비트 동일, 코사인 ≥0.998). 한 개씩은 결정론적이고 문맥 크기와 무관. 색인을 다시 만들면 벡터가 미세하게 바뀔 수 있다 → 기준점은 색인 백업과 묶어 기록.
- Chroma `/api/v2/version`은 1.0.0·1.5.5 이미지 모두 `"1.0.0"` → 버전은 이미지 ID·`chroma --version`(1.5.5 이미지는 1.4.1)으로 확인.
- 데스크탑 `.env`: `OLLAMA_NUM_CTX=8192`, `OLLAMA_EMBEDDING_NUM_CTX=2048`(원본 `.env.bak-20261003-before-pr2`). 원격 빌드는 `DOCKER_CONFIG=~/.docker-nocreds`(빈 config)로. 데스크탑에 `.wslconfig`가 없어 Ubuntu 창을 닫으면 WSL이 꺼진다.
- **생성 모델 EXAONE 3.5는 연구 목적 전용 라이선스(NC 1.1, E5)**: 파생 모델도 연구용, 출력으로 다른 모델 학습 금지. 4.0/4.5는 연구·교육 목적(공식 챗봇 해당 여부 불분명), K-EXAONE 2.0은 Apache 2.0이나 750B. 서비스 가능 대안(원문 확인): A.X 4.0 Light(Apache 2.0), Mi:dm 2.0(MIT), Kanana 1.5(Apache 2.0), Qwen3/3.5(Apache 2.0). 상세: `docs/rag/research/생성모델-라이선스-및-학습데이터-조사-20261001.md`. **기반 모델은 학습 전에 M1 평가셋으로 비교 후보 4개(안건 1 확장안)를 EXAONE 기준점과 비교해 고른다.** AI 기본법(2026-01-22 시행) 제31조의 사전 고지·결과물 표시 의무는 어떤 모델을 쓰든 적용된다(반영 위치는 안건 5). 학습 데이터 생성은 EXAONE 금지, Claude는 약관 해석 문제 → Apache 2.0 오픈 모델 권장.
